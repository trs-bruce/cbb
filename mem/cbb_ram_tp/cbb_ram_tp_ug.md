## 1. 功能及应用场景

### 1.1 核心功能

CBB_RAM_TP 是一款参数化的 **2PRF（Simple Dual Port）同步 SRAM**，提供 **两个独立端口**：Port-A 专用于写操作，Port-B 专用于读操作，两端口拥有 **独立的时钟域**（`mem_a_clk` / `mem_b_clk`），支持同步或异步时钟操作。两端口共享同一存储阵列，无内部冲突仲裁逻辑（2PRF 天然避免读写冲突）。

**核心功能特性：**

| 功能 | 说明 |
|------|------|
| **2PRF 架构** | Port-A 只写（Write-only），Port-B 只读（Read-only），独立地址与数据通路 |
| **独立双时钟** | 写时钟 `mem_a_clk` 与读时钟 `mem_b_clk` 完全独立，支持同频/异频/异步操作 |
| **同步写操作** | 写操作在 `mem_a_clk` 上升沿触发，受 `mem_a_cs` 和 `mem_a_we` 控制，支持 `mem_a_bwe` 逐位掩码 |
| **同步读操作** | 读操作在 `mem_b_clk` 上升沿触发，固定 1 拍延迟寄存器输出，受 `mem_b_cs` 控制 |
| **独立片选控制** | `mem_a_cs` / `mem_b_cs` 高有效，分别控制写/读端口使能；`mem_a_cs=0` 时写禁止，`mem_b_cs=0` 时读输出保持 |
| **逐位写掩码** | `mem_a_bwe` 高有效，逐位门控写操作，未被置位的数据位保持原值 |
| **参数化位宽与深度** | 数据位宽 `MEM_DATA_WIDTH` 与地址位宽 `MEM_ADDR_WIDTH` 可独立配置 |
| **初始化文件加载** | 支持 `$readmemh` 加载初始化数据（行为级仿真） |
| **三工艺支持** | 支持 TSMC_12 硬宏 / FPGA_XILINX / FPGA_ALTERA |

**顶层框图：**

```
    ┌────────────────────────┐
    │                        │
  ──┤ mem_a_clk              │
    │                        │
  ──┤ mem_b_clk              │
  ──┤ mem_a_cs               │
    │                        │
  ──┤ mem_b_cs               │
  ──┤ mem_a_we               │
  ──┤ mem_a_bwe              │
  ──┤ mem_a_addr             │
  ──┤ mem_a_wdata            │
    │            mem_b_rdata ├─────
  ──┤ mem_b_addr             │
    └────────────────────────┘
```

### 1.2 适用场景

| 场景 | 说明 |
|------|------|
| **视频帧缓冲** | 写端口持续写入当前帧，读端口独立读出上一帧用于显示，双时钟支持像素时钟与系统时钟分离 |
| **异步 FIFO 存储** | 写侧与读侧处于不同时钟域，2PRF 天然适合作为异步 FIFO 的存储核心 |
| **数据缓冲与流控** | 上游模块以高速时钟突发写入，下游模块以低速时钟顺序读出，独立时钟简化跨域设计 |
| **乒乓缓冲** | 双 TP 模块交替作为读/写目标，实现无停顿数据流切换 |
| **查找表实时更新** | 写端口后台更新表项，读端口持续查表读取，读写并发无阻塞 |
| **多主设备共享存储** | 单一写主设备通过 Port-A 更新数据，多读主设备通过 Port-B 并发读取 |

## 2. 规格

每条规格以 DS 点编号标识，命名规则为 `DS.[IP_NAME].[TYPE][SPEC_ID]`。TYPE 取值：`FUNC`（功能）、`PERF`（性能）、`INTF`（接口）、`CFG`（配置）。

### 规格汇总

| DS 编号 | 类型 | 规格概述 |
|---------|------|----------|
| DS.CBB_RAM_TP.FUNC.001 | FUNC | 提供两个独立端口：Port-A 只写，Port-B 只读，各含独立地址、数据与控制信号 |
| DS.CBB_RAM_TP.FUNC.002 | FUNC | 写操作在 `mem_a_clk` 上升沿触发，受 `mem_a_cs` 和 `mem_a_we` 控制，由 `mem_a_bwe` 逐位掩码 |
| DS.CBB_RAM_TP.FUNC.003 | FUNC | 读操作在 `mem_b_clk` 上升沿触发，固定 1 拍延迟寄存器输出，受 `mem_b_cs` 控制 |
| DS.CBB_RAM_TP.FUNC.004 | FUNC | 独立片选控制：`mem_a_cs` / `mem_b_cs` 高有效；`mem_a_cs=0` 时写禁止，`mem_b_cs=0` 时读输出保持前值 |
| DS.CBB_RAM_TP.FUNC.005 | FUNC | `mem_a_we` 写使能高有效：`mem_a_we=0` 时写操作被禁止 |
| DS.CBB_RAM_TP.FUNC.006 | FUNC | 写时钟 `mem_a_clk` 与读时钟 `mem_b_clk` 完全独立，支持同步或异步操作 |
| DS.CBB_RAM_TP.FUNC.007 | FUNC | 支持通过 `$readmemh` 加载初始化文件 |
| DS.CBB_RAM_TP.CFG.001 | CFG | 数据位宽由 `MEM_DATA_WIDTH` 参数配置 |
| DS.CBB_RAM_TP.CFG.002 | CFG | 存储深度由 `MEM_ADDR_WIDTH` 参数配置，深度 = 2^MEM_ADDR_WIDTH（`MEM_DEPTH` 为内部 localparam） |
| DS.CBB_RAM_TP.INTF.001 | INTF | 控制信号悬空语义：`mem_a_cs=0` 或 `mem_a_we=0` 时写禁止；`mem_b_cs=0` 时读输出保持前值 |
| DS.CBB_RAM_TP.PERF.001 | PERF | 写延迟固定 1 拍（`mem_a_clk` 沿生效）；读延迟固定 1 拍（`mem_b_clk` 沿采样，下一周期输出） |
| DS.CBB_RAM_TP.PERF.002 | PERF | 并发吞吐率：每 `mem_a_clk` 周期可完成 1 次写，每 `mem_b_clk` 周期可完成 1 次读，读写完全并行 |

### 2.1 2PRF 架构 — DS.CBB_RAM_TP.FUNC.001

模块提供两个功能独立的端口，共享同一存储阵列：

| 端口 | 功能 | 时钟 | 控制 | 地址 | 数据 |
|------|------|------|------|------|------|
| Port-A | 只写 | `mem_a_clk` | `mem_a_cs` + `mem_a_we` + `mem_a_bwe` | `mem_a_addr` | `mem_a_wdata` |
| Port-B | 只读 | `mem_b_clk` | `mem_b_cs` | `mem_b_addr` | `mem_b_rdata` |

- Port-A 与 Port-B 时钟完全独立，可同频、异频或异步
- 无内部冲突仲裁逻辑（2PRF 架构天然避免读写冲突，因两端口功能互斥）
- 若写地址与读地址相同，读端口输出的是 **写操作完成前的旧数据**（由 Verilog 非阻塞赋值语义保证）

### 2.2 同步写操作 — DS.CBB_RAM_TP.FUNC.002

写操作在 `mem_a_clk` 上升沿触发。当 `mem_a_cs == 1'b1 && mem_a_we == 1'b1` 时，`mem_a_wdata` 按 `mem_a_bwe` 掩码逐位写入 `mem_a_addr` 地址：仅 `mem_a_bwe[i]==1'b1` 的位被更新，其余位保持原值。片选或写使能无效时，写操作被禁止。

| 条件 | 行为 |
|------|------|
| `mem_a_cs=1, mem_a_we=1` | `mem[addr][i] <= wdata[i]`（仅 `mem_a_bwe[i]=1` 的位） |
| `mem_a_cs=1, mem_a_we=0` | 无写操作 |
| `mem_a_cs=0` | 无写操作（片选无效） |

### 2.3 同步读操作 — DS.CBB_RAM_TP.FUNC.003

读操作在 `mem_b_clk` 上升沿触发，输出为 **固定 1 拍延迟的寄存器输出**：

- 当 `mem_b_cs == 1'b1` 时，`mem_b_addr` 在 `mem_b_clk` 上升沿被采样
- 下一 `mem_b_clk` 周期，`mem_b_rdata` 输出对应地址数据
- `mem_b_cs=0` 时，`mem_b_rdata` 保持前值（不更新）

| `mem_b_cs` | `mem_b_clk` 沿 | `mem_b_rdata` | 行为 |
|:---:|:---|:---|:---|
| 1 | ↑ | `mem[addr]`（1 拍后） | 读操作 |
| 0 | ↑ | 保持前值 | 片选无效 |

### 2.4 片选控制 — DS.CBB_RAM_TP.FUNC.004

- `mem_a_cs`（Port-A Chip Select，**高有效**）：写端口片选。`mem_a_cs=1` 时允许写操作；`mem_a_cs=0` 时写操作被禁止。
- `mem_b_cs`（Port-B Chip Select，**高有效**）：读端口片选。`mem_b_cs=1` 时允许读操作；`mem_b_cs=0` 时 `mem_b_rdata` 保持前值。
- 两端口片选相互独立，可分别使能或禁用。

### 2.5 写使能控制 — DS.CBB_RAM_TP.FUNC.005

- `mem_a_we`（Write Enable，**高有效**）：写使能信号。`mem_a_we=1` 时允许写；`mem_a_we=0` 时写操作被禁止。
- `mem_a_bwe`（Bit Write Enable，**高有效**）：逐位写掩码，位宽与 `MEM_DATA_WIDTH` 一致。写操作时仅 `mem_a_bwe[i]==1'b1` 对应的数据位被更新，其余位保持原值，可实现字节写或逐位屏蔽写。

### 2.6 独立双时钟 — DS.CBB_RAM_TP.FUNC.006

- `mem_a_clk`：驱动 Port-A 写操作，所有写相关信号（`mem_a_cs`、`mem_a_we`、`mem_a_bwe`、`mem_a_addr`、`mem_a_wdata`）均同步于此时钟
- `mem_b_clk`：驱动 Port-B 读操作，所有读相关信号（`mem_b_cs`、`mem_b_addr`）均同步于此时钟，输出 `mem_b_rdata` 也在此时钟域更新
- 两时钟完全独立，支持：
  - **同步模式**：`mem_a_clk` 与 `mem_b_clk` 同源同频
  - **异步模式**：`mem_a_clk` 与 `mem_b_clk` 为独立时钟源（需调用者保证跨时钟域数据一致性）

### 2.7 参数化初始化 — DS.CBB_RAM_TP.FUNC.007

支持两种初始化方式：

- **全零初始化**：上电后所有存储单元自动清零（默认）
- **文件初始化**：通过 `INIT_FILE` 参数指定 `.hex` 文件路径，仿真阶段加载初始值；TSMC_12 模式下 `INIT_FILE` 被忽略，存储内容由硬宏内部固化

### 2.8 数据位宽配置 — DS.CBB_RAM_TP.CFG.001

`MEM_DATA_WIDTH` 决定每个存储单元的位宽，可配置为 **≥ 1 的任意正整数**。

- 默认值：32（对齐 256x32 两端口宏的位宽）
- 典型配置：8, 16, 32, 64

### 2.9 存储深度与地址位宽配置 — DS.CBB_RAM_TP.CFG.002

- `MEM_ADDR_WIDTH` 决定地址总线位宽，存储深度 = **2^MEM_ADDR_WIDTH**
- `MEM_DEPTH` 为内部 localparam（= 2^MEM_ADDR_WIDTH），不可由外部覆盖
- 默认深度：256（`MEM_ADDR_WIDTH=8`，与 TSMC 宏对齐）
- 典型配置：4（16 字）、8（256 字）、10（1024 字）

### 2.10 写延迟与读延迟 — DS.CBB_RAM_TP.PERF.001

- **写延迟**：固定 1 拍（`mem_a_clk` 上升沿写入）
- **读延迟**：固定 1 拍（`mem_b_clk` 上升沿采样地址，下一周期输出有效数据）
- 跨时钟域场景下，写操作完成后需等待至少一个 `mem_b_clk` 周期，读端口方可看到更新数据

### 2.11 并发吞吐 — DS.CBB_RAM_TP.PERF.002

- 每 `mem_a_clk` 周期最多完成 1 次写操作
- 每 `mem_b_clk` 周期最多完成 1 次读操作
- 读写操作完全并行，互不阻塞

## 3. 方案分析

### 3.1 原理分析

2PRF（Simple Dual Port）SRAM 在单端口基础上将读写端口物理分离，写端口仅含地址/数据/写使能，读端口仅含地址/读使能/数据输出。核心优势在于**读写时钟完全独立**，天然支持跨时钟域应用，且无需内部冲突仲裁逻辑（因同一端口不会同时读写）。

**综合映射说明：**

本设计采用标准 Verilog 寄存器数组建模：

```verilog
reg [MEM_DATA_WIDTH-1:0] mem [0:MEM_DEPTH-1];
```

综合工具将根据目标工艺和容量自动选择最优实现方式：

| 容量 | 典型实现方式 | 说明 |
|------|-------------|------|
| 小深度（≤ 64 字） | 触发器（DFF）阵列 | 综合工具自动推断为寄存器阵列，访问速度快 |
| 中深度（64 ~ 256 字） | 分布式 RAM / LUT-RAM | 面积与性能的折中，适用于 FPGA |
| 大深度（> 256 字） | SRAM 宏 | 面积最优，需目标工艺库支持，综合工具可自动推断 |

**本设计采用行为级 RTL 描述**，不绑定任何特定工艺库。综合工具可根据目标工艺自由选择 DFF 阵列或 SRAM 宏实现，兼顾通用性与可移植性。

### 3.2 写操作设计

写端口受 `mem_a_cs` 和 `mem_a_we` 控制，仅在 `mem_a_clk` 上升沿触发；`mem_a_bwe` 逐位门控写入：

```verilog
always @(posedge mem_a_clk)
begin : MEM_WRITE_PROC
    if ((mem_a_cs == 1'b1) && (mem_a_we == 1'b1))
    begin
        for (i = 0; i < MEM_DATA_WIDTH; i = i + 1)
            if (mem_a_bwe[i] == 1'b1)
                mem[mem_a_addr][i] <= mem_a_wdata[i];
    end
end
```

- `mem_a_we` 为 **高有效**（`1` = 写使能，`0` = 写禁止），TSMC 硬宏侧经反相接 `WEB`
- `mem_a_bwe` 为 **高有效** 逐位掩码，仅置位位被更新；TSMC 硬宏侧经反相接 `BWEB`
- 片选无效时写操作被禁止
- 无复位参与存储阵列

### 3.3 读操作设计

读端口受 `mem_b_cs` 控制，固定 1 拍延迟寄存器输出：

```verilog
always @(posedge mem_b_clk)
begin : MEM_READ_PROC
    if (mem_b_cs == 1'b1)
    begin
        mem_b_rdata <= mem[mem_b_addr];
    end
end
```

- `mem_b_cs` 为 **高有效**（`1` = 读使能，`0` = 读禁止），TSMC 硬宏侧经反相接 `REB`
- 输出经寄存器缓冲，改善时序裕量
- 片选无效时，输出寄存器保持原值
- 若写地址与读地址相同，读端口输出的是 **写操作前的旧数据**（由 Verilog 非阻塞赋值语义天然保证）

### 3.4 跨时钟域行为

由于 `mem_a_clk` 与 `mem_b_clk` 独立，写操作与读操作处于不同时钟域：

- **同频同步**：`mem_a_clk` 与 `mem_b_clk` 同源，写后读延迟固定为 1~2 个时钟周期（取决于相位关系）
- **异步模式**：写操作在 `mem_a_clk` 沿生效后，需经过 CDC 同步时间才能在 `mem_b_clk` 域被读出；调用者需通过握手或 FIFO 逻辑保证数据一致性
- **行为级模型**：`mem` 数组为共享存储，DUT 与参考模型均使用非阻塞赋值，确保仿真行为与真实硬件一致

## 4. 配置参数

| 参数 | 配置范围 | 默认值 | 描述 |
|------|----------|--------|------|
| `MEM_DATA_WIDTH` | 1 ~ 1024 | 32 | 每个存储单元的数据位宽，与 TSMC 宏 32-bit 对齐 |
| `MEM_ADDR_WIDTH` | 1 ~ 16 | 8 | 地址总线位宽，深度 = 2^MEM_ADDR_WIDTH，与 TSMC 宏 256-word 对齐 |
| `INIT_FILE` | 字符串 | "" | 初始化文件路径，空字符串表示全零初始化；TSMC 模式下忽略 |

**配置约束关系：**

- `MEM_DATA_WIDTH`、`MEM_ADDR_WIDTH`、`INIT_FILE` 相互独立
- `MEM_DEPTH` 为内部 localparam（= 2^MEM_ADDR_WIDTH），不可由外部覆盖
- 默认配置 `MEM_DATA_WIDTH=32, MEM_ADDR_WIDTH=8` 对应 256×32 两端口宏（占位名 `CBB_SRAM_256X32_2P`）
- 大容量需求由上层例化多个 `CBB_RAM_TP` 并做 width/depth banking 实现，CBB 层不做内部 banking

## 5. 接口

> **特别说明**：
> - 模块 **无复位端口**（`rst_n`），存储阵列本身无复位，上电初态由 `INIT_FILE` 或全零初始化决定。
> - `mem_a_cs`、`mem_b_cs`、`mem_a_we`、`mem_a_bwe` 均为 **高有效** 信号，正常工作时需驱动为 `1`。
> - 当 `mem_a_cs=0` 或 `mem_a_we=0` 时写操作被禁止；当 `mem_b_cs=0` 时 `mem_b_rdata` 保持前值（不更新）。
> - `mem_a_clk` 与 `mem_b_clk` 完全独立，可接同一时钟或独立时钟源。

| 信号名 | 位宽 | I/O | 时钟域 | 描述 |
|--------|------|-----|--------|------|
| `mem_a_clk` | 1 | I | `mem_a_clk` | 写时钟，Port-A 写操作在上升沿触发 |
| `mem_b_clk` | 1 | I | `mem_b_clk` | 读时钟，Port-B 读操作在上升沿触发 |
| `mem_a_cs` | 1 | I | `mem_a_clk` | **写端口片选，高有效**。`1` 时允许写，`0` 时写禁止 |
| `mem_b_cs` | 1 | I | `mem_b_clk` | **读端口片选，高有效**。`1` 时允许读，`0` 时读输出保持 |
| `mem_a_we` | 1 | I | `mem_a_clk` | **写使能，高有效**。`1` 时允许写，`0` 时写禁止 |
| `mem_a_bwe` | `MEM_DATA_WIDTH` | I | `mem_a_clk` | **逐位写使能，高有效**。`mem_a_bwe[i]=1` 时写对应 bit，`0` 时保持原值 |
| `mem_a_addr` | `MEM_ADDR_WIDTH` | I | `mem_a_clk` | 写地址 |
| `mem_a_wdata` | `MEM_DATA_WIDTH` | I | `mem_a_clk` | 写数据 |
| `mem_b_addr` | `MEM_ADDR_WIDTH` | I | `mem_b_clk` | 读地址 |
| `mem_b_rdata` | `MEM_DATA_WIDTH` | O | `mem_b_clk` | 读数据输出，寄存器输出，1 拍延迟 |

### 5.1 端口操作真值表

| `mem_a_cs` | `mem_a_we` | `mem_a_bwe` | `mem_a_clk` 沿 | 写行为 |
|:---:|:---:|:---:|:---|:---|
| 1 | 1 | 非全 0 | ↑ | `mem[addr][i]<=wdata[i]`（仅 `mem_a_bwe[i]=1` 的位） |
| 1 | 1 | 全 0 | ↑ | 无（掩码全零，无位更新） |
| 1 | 0 | x | ↑ | 无 |
| 0 | x | x | ↑ | 无 |

| `mem_b_cs` | `mem_b_clk` 沿 | 读行为 | `mem_b_rdata` |
|:---:|:---|:---|:---|
| 1 | ↑ | `rdata<=mem[addr]` | 1 拍后更新 |
| 0 | ↑ | 无 | 保持前值 |

### 5.2 TSMC 12nm 宏端口映射

**宏型号**：占位名 `CBB_SRAM_256X32_2P`（256 words × 32 bits，2PRF；实际型号由后端 Memory Compiler 决定）

## 6. 时序图

### 6.1 写操作时序（Port A）

```
            T0      T1      T2      T3      T4
            _       _       _       _       _
mem_a_clk _| |_____| |_____| |_____| |_____| |_

mem_a_cs  ________/‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾\________

mem_a_we  ________/‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾\________

mem_a_bwe ________/全 1‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾\________
                    ↑       ↑       ↑
mem_a_addr  ───X  0x2  X───X  0x5  X───X  0x2  X──
mem_a_wdata ───X  0xA5 X───X  0x3C X───X  0x7B X──
                    ↑       ↑       ↑
mem[2]             0xA5                    0x7B
mem[5]                     0x3C
```

**说明**：`mem_a_cs` 和 `mem_a_we` 在整个写操作期间保持高电平（有效），`mem_a_bwe` 为全 1（整字写入）。T1 `mem_a_clk` 上升沿，`mem_a_addr=0x2`，`mem_a_wdata=0xA5`，写入 mem[2]；T2 写入 mem[5] 为 0x3C；T4 再次写入 mem[2] 为 0x7B。若 `mem_a_bwe` 仅部分位置 1，则只有对应 bit 被更新，其余位保持原值。

### 6.2 读操作时序（Port B）

```
            T0      T1      T2      T3      T4
            _       _       _       _       _
mem_b_clk _| |_____| |_____| |_____| |_____| |_

mem_b_cs  ________/‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾
                    ↑       ↑       ↑
mem_b_addr  ───X  0x2  X───X  0x5  X───X  0x2  X──
                    │       │       │
mem_b_rdata ───X 0xA5 X───X 0x3C X───X 0x7B X
                    ↑       ↑       ↑
                 输出旧值  输出新值  输出新值
```

**说明**：`mem_b_cs` 保持高电平（读使能）。T1 `mem_b_clk` 上升沿采样 `mem_b_addr=0x2`，T2 `mem_b_rdata` 输出 mem[2] = 0xA5；T2 采样 `mem_b_addr=0x5`，T3 输出 mem[5] = 0x3C。读延迟固定为 1 拍。

### 6.3 跨时钟域读写一致性时序

```
mem_a_clk    _       _       _       _       _
            | |_____| |_____| |_____| |_____| |_
mem_a_cs    ________/‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾
mem_a_we    ________/‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾
mem_a_bwe   ________/全 1‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾
mem_a_addr  ───X  0x2  X───────────────────────────
mem_a_wdata ───X  0x3C X───────────────────────────
                    ↑
mem[2]             0x3C    (T1 写入完成)

mem_b_clk   _       _       _       _       _       _
           | |_____| |_____| |_____| |_____| |_____| |_
mem_b_cs   ________/‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾
mem_b_addr ───────────X  0x2  X─────────────────────
                             │
mem_b_rdata ───────────────────X 0xA5 X───X 0x3C X──
                             ↑       ↑
                          输出旧值  输出新值
                          (写前)   (写后 1 拍)
```

**说明**：T1 `mem_a_clk` 沿写入 0x3C 到 mem[2]。由于 `mem_b_clk` 独立，读端口在 T2 采样地址 0x2 时，若写尚未传播，仍输出旧值 0xA5；T3 输出更新后的 0x3C。跨时钟域下写后读需至少等待 1 个 `mem_b_clk` 周期方可确保数据一致性。

### 6.4 控制信号极性验证时序

```
         T0      T1      T2      T3      T4      T5
              _       _       _       _       _       _
mem_a_clk   _| |_____| |_____| |_____| |_____| |_____| |_

mem_a_cs    ________/‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾
                    ____________
mem_a_we    _______/            \_______________________
mem_a_bwe   ‾‾‾‾‾‾‾‾全 1‾‾‾‾‾‾‾‾全 1‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾
                    ↑       ↑       ↑
mem_a_wdata ───X  0xFF X───X  0xAA X─────────────────
mem_a_addr  ───X  0x0  X───X  0x0  X─────────────────
                    │       │       │
mem[0]             0x00    0x00    0x00    (a_cs=0 时写被屏蔽)

mem_a_we    ‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾
mem_a_cs    ________/‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾
mem_a_wdata ───────────────────X  0xBB X─────────────
mem_a_addr ───────────────────X  0x0  X─────────────
                                     ↑
mem[0]                          0xBB    (a_we=1 时写入)
```

**说明**：T1~T2 `mem_a_cs=0`，尽管 `mem_a_we=1`，写操作被屏蔽，mem[0] 保持 0x00；T4~T5 `mem_a_cs=1` 且 `mem_a_we=1`，0xBB 成功写入 mem[0]。验证了 `mem_a_cs` 和 `mem_a_we` 高有效极性。

### 7.7 时序说明

- **写端口关键路径**：`mem_a_cs` / `mem_a_we` / `mem_a_bwe` / `mem_a_addr` / `mem_a_wdata` → 存储阵列建立时间，受 `mem_a_clk` 周期约束
- **读端口关键路径**：`mem_b_cs` / `mem_b_addr` → 输出寄存器建立时间，受 `mem_b_clk` 周期约束
- **跨时钟域路径**：写操作在 `mem_a_clk` 域生效后，到 `mem_b_clk` 域可读出的时间不属于单一时钟域时序分析范围，需调用者在系统级通过 CDC 设计保证
- **高扇出影响**：大容量配置（如 64×10）中时钟网和数据线扇出极大，综合工具采用扇出模型估算延迟；物理实现阶段需通过时钟树综合（CTS）和缓冲插入优化
