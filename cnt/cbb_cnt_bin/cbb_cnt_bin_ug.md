## 1. 功能及应用场景

### 1.1 核心功能

`cbb_cnt_bin` 是基于串行进位加法器（Ripple Carry Adder，RCA）的参数化全同步加减计数器。复位、计数、清零、置数和方向控制均在 `clk` 上升沿同步生效。

模块集成以下功能：

- 参数化计数位宽 `WIDTH`
- 计数使能 `en`
- 同步清零 `sync_clr`
- 并行动态置数 `load` 和置数值 `init_val`
- 通过 `dir` 实时选择递增或递减计数
- 上、下边界检测
- 可配置的边界回绕或边界锁存行为
- 进位/借位指示 `cout`

当 `en=1` 时，模块在每个时钟上升沿按照 `dir` 指定的方向加 1 或减 1；当 `en=0` 且没有更高优先级控制有效时，计数值保持不变。回绕模式下，计数越过边界后从另一端继续计数；锁存模式下，计数值停留在边界，方向反转后可离开边界继续计数。

`load` 可在无需复位的情况下于时钟沿直接装载新的计数值。计数输出 `q` 为寄存器输出，只要同步输入满足建立时间和保持时间要求，置数过程不会在 `q` 上产生组合毛刺。

### 1.2 解决的问题

该模块提供统一的可配置双向计数数据通路，避免不同业务模块重复实现计数使能、初值加载、边界处理和方向切换逻辑。RCA 结构简单、面积开销较小、逻辑结构清晰，适用于对通用性和资源开销更敏感的小、中位宽计数场景。

由于 RCA 的进位/借位逐位串行传播，关键路径随 `WIDTH` 增长，最大工作频率通常随位宽增加而下降。对大位宽或高频场景，应结合目标工艺的综合时序结果评估是否改用超前进位、前缀加法器或预定标计数结构。

### 1.3 应用场景

| 场景           | 典型用法                                            |
| -------------- | --------------------------------------------------- |
| 通用定时与分频 | 统计时钟周期，通过边界指示或外部比较器产生周期事件  |
| 状态机辅助计数 | 记录状态驻留周期、循环次数或事件次数                |
| 可编程分频器   | 使用`load` 装载初值，结合 `cout` 形成可配置周期 |
| 协议帧计数     | 统计接收、发送或处理完成的帧数                      |
| 位置跟踪       | 通过递增/递减方向跟踪离散位置变化                   |
| 队列深度统计   | 入队时递增、出队时递减，并使用边界锁存避免越界      |
| 双向流量计数   | 根据流量方向动态切换加减模式                        |
| 重传计数       | 统计重传次数，并在达到上限时通过边界信号告警        |
| 事件计数       | 将同步后的事件脉冲接入`en` 进行累计               |
| 循环寻址       | 在回绕模式下生成循环地址或环形索引                  |

> 外部异步事件不能直接作为同步控制信号使用，应先在调用方完成同步和脉冲整形。

## 2. 规格

| DS编号                  | 类型 | 简述                                                                             |
| ----------------------- | ---- | -------------------------------------------------------------------------------- |
| DS.CBB_CNT_BIN.FUNC.001 | FUNC | 计数方向：`dir=0` 加 1，`dir=1` 减 1，方向可实时切换。                       |
| DS.CBB_CNT_BIN.FUNC.002 | FUNC | 控制优先级：`rst_n > load > sync_clr > en > hold`。                            |
| DS.CBB_CNT_BIN.FUNC.003 | FUNC | 复位行为：同步低有效复位，在时钟上升沿采样到`rst_n=0` 后令 `q=0`。           |
| DS.CBB_CNT_BIN.FUNC.004 | FUNC | 溢出行为：`OVERFLOW_WRAP=1` 时边界回绕；为 0 时锁存在 `MAX` 或 0。           |
| DS.CBB_CNT_BIN.FUNC.005 | FUNC | 进位/借位输出：`cout` 为组合输出；回绕模式为边界脉冲，锁存模式为边界驻留电平。 |
| DS.CBB_CNT_BIN.FUNC.006 | FUNC | 同步清零：`sync_clr=1` 时，下一个时钟上升沿将 `q` 清零。                     |
| DS.CBB_CNT_BIN.FUNC.007 | FUNC | 动态置数：`load=1` 时，下一个时钟上升沿将 `init_val` 装载到 `q`。          |
| DS.CBB_CNT_BIN.FUNC.008 | FUNC | 数值保持：`en=0` 且无更高优先级控制有效时，`q` 保持不变。                    |

### 2.1 计数方向 — DS.CBB_CNT_BIN.FUNC.001

| dir | 行为              |
| --- | ----------------- |
| 0   | 加 1 计数（Up）   |
| 1   | 减 1 计数（Down） |

`dir` 可按周期动态切换。模块在每个有效时钟上升沿采样当前方向，不要求插入空闲周期。`dir` 必须满足相对于 `clk` 的建立时间和保持时间要求。

### 2.2 控制优先级 — DS.CBB_CNT_BIN.FUNC.002

```text
rst_n（最高） > load > sync_clr > en > hold
```

- `rst_n=0`：在时钟上升沿将 `q` 清零，其他控制无效。
- `rst_n=1` 且 `load=1`：在时钟上升沿装载 `init_val`。
- `load=0` 且 `sync_clr=1`：在时钟上升沿将 `q` 清零。
- 更高优先级控制均无效且 `en=1`：执行一次加 1 或减 1。
- 上述控制均无效：保持当前计数值。

### 2.3 复位行为 — DS.CBB_CNT_BIN.FUNC.003

`rst_n` 为同步低有效复位信号。模块仅在 `clk` 上升沿采样 `rst_n`：若采样到 `rst_n=0`，则在该时钟沿将 `q` 清零，并忽略 `load`、`sync_clr`、`en` 和 `dir`；若 `rst_n` 在两个有效时钟沿之间变化，`q` 不会立即变化。`rst_n` 的拉低和释放均应满足相对于 `clk` 的建立时间和保持时间要求。

### 2.4 溢出行为 — DS.CBB_CNT_BIN.FUNC.004

`MAX` 定义为 `{WIDTH{1'b1}}`。

| OVERFLOW_WRAP | 加到 MAX 后继续加 | 减到 0 后继续减 |
| ------------- | ----------------- | --------------- |
| 1（默认）     | 回绕到 0          | 回绕到`MAX`   |
| 0             | 锁存在`MAX`     | 锁存在 0        |

锁存模式下，如果 `dir` 保持指向越界方向，则 `q` 停留在边界；如果 `dir` 反转且 `en=1`，则 `q` 在下一个时钟上升沿离开边界并向反方向计数。`load` 和 `sync_clr` 也可使计数器离开边界。

### 2.5 进位/借位输出 — DS.CBB_CNT_BIN.FUNC.005

`cout` 为基于当前 `q`、`en`、`dir` 和 `rst_n` 生成的组合输出：

- 加法方向且 `q==MAX` 且 `en=1`：`cout=1`，表示进位或上边界事件。
- 减法方向且 `q==0` 且 `en=1`：`cout=1`，表示借位或下边界事件。
- `rst_n=0` 或 `en=0`：`cout=0`。
- 回绕模式：若方向和使能保持稳定，计数器下一拍离开边界，因此 `cout` 通常持续一个时钟周期。
- 锁存模式：计数器持续停留在边界时，`cout` 保持高电平，直到 `en=0`、方向反转或其他高优先级控制使其离开边界。

> `cout` 在锁存模式下不是单周期事件脉冲。需要单周期事件语义时，调用方应对 `cout` 做边沿检测，或将 `cout` 与首次到达边界的状态组合使用。

### 2.6 同步清零 — DS.CBB_CNT_BIN.FUNC.006

当 `sync_clr=1`、`load=0` 且 `rst_n=1` 时，`q` 在下一个 `clk` 上升沿同步变为 0。同步清零优先级高于计数使能，低于动态置数和同步复位。

### 2.7 动态置数 — DS.CBB_CNT_BIN.FUNC.007

当 `load=1` 且 `rst_n=1` 时，`q` 在下一个 `clk` 上升沿装载 `init_val`。动态置数优先级仅低于同步复位，可用于运行过程中更换初始值、跳转计数位置或快速恢复指定状态。

置数通过寄存器输入端的多路选择逻辑完成。`q` 为寄存器输出，因此在 `load` 和 `init_val` 满足同步时序要求的前提下，置数不会在 `q` 上产生组合毛刺。

### 2.8 数值保持 — DS.CBB_CNT_BIN.FUNC.008

当 `rst_n=1`、`load=0`、`sync_clr=0` 且 `en=0` 时，计数寄存器不更新，`q` 保持当前值不变。`dir` 和 `init_val` 在保持期间发生变化不会改变 `q`。

## 3. 方案分析

### 3.1 原理分析

计数器由状态寄存器、加减运算单元、边界检测逻辑和控制多路选择器组成。寄存器保存当前计数值，RCA 计算候选的 `q+1` 或 `q-1`，边界逻辑决定采用正常结果、回绕结果或边界保持值，控制多路选择器再按照优先级选择最终写入值。

```text
                          ┌─────────────┐
init_val ────────────────▶│             │
0 ───────────────────────▶│ 控制 MUX     │──▶ q_reg ──▶ q
q ───────────────────────▶│             │      │
next_count ──────────────▶│             │      │
                          └─────────────┘      │
                                               ▼
                         ┌─────────────────────────────┐
                         │ RCA + 边界检测 + wrap/sat  │
                         └─────────────────────────────┘
```

### 3.2 主流实现方法对比

| 方案                  | 关键路径特征                | 优点                       | 缺点                     | 适用场景             |
| --------------------- | --------------------------- | -------------------------- | ------------------------ | -------------------- |
| RCA                   | 进位逐位传播，约为 O(N)     | 结构简单、面积小、易参数化 | 位宽增加时延迟明显增加   | 小、中位宽通用计数器 |
| 超前进位加法器（CLA） | 分组计算进位                | 速度高于 RCA               | 控制逻辑和布线更复杂     | 中等位宽、较高频率   |
| 前缀加法器            | 树形进位网络，约为 O(log N) | 大位宽性能较好             | 面积与布线开销较大       | 大位宽高性能计数     |
| 预定标/分段计数       | 高频低位与低频高位分离      | 可缩短每拍关键路径         | 控制和进位事件处理更复杂 | 高频宽位计数器       |

### 3.3 选定方案

本模块选择“显式 RCA + 边界检测 + 回绕/锁存配置”方案，主要原因如下：

1. 默认位宽为 8 bit，属于 RCA 适用的小位宽范围。
2. 每一位只需要简单的异或和进位/借位逻辑，结构清晰且便于综合和时序定位。
3. 递增和递减路径可以复用同一组逐位传播结构。
4. 边界回绕与锁存通过少量比较和选择逻辑实现，不改变接口形式。
5. 位宽较大或频率要求较高时，可根据综合结果替换运算结构，而不改变模块级控制语义。

### 3.4 RCA 加减实现

RCA 从最低位开始传播进位或借位。初始传播量为 1，表示执行一次加 1 或减 1：

```text
rca_chain[0]   = 1'b1
rca_val[k]     = q[k] ^ rca_chain[k]
rca_chain[k+1] = (dir == 1'b0)
                   ? ( q[k] & rca_chain[k])
                   : (~q[k] & rca_chain[k])
```

- 递增时，仅当当前位为 1 且收到进位时，继续向高位传播进位。
- 递减时，仅当当前位为 0 且收到借位时，继续向高位传播借位。
- `rca_val` 是未考虑边界策略的候选计数值。

传播链如下：

```text
chain[0]=1 → bit[0] → chain[1] → bit[1] → ... → bit[WIDTH-1] → chain[WIDTH]
```

### 3.5 边界处理

组合逻辑预先计算：

```text
at_max  = (q == MAX)
at_min  = (q == 0)
wrap_up = en && !dir && at_max
wrap_dn = en &&  dir && at_min
```

正常情况下，下一计数值采用 `rca_val`。边界事件发生时：

- 回绕模式：上边界的下一值选择 0，下边界的下一值选择 `MAX`。
- 锁存模式：继续朝越界方向计数时选择当前边界值。
- 锁存模式下方向反转后，边界条件不再指向越界方向，下一拍采用 `rca_val` 离开边界。

### 3.6 控制实现

寄存器更新逻辑按以下顺序执行：

```text
同步复位 → 动态置数 → 同步清零 → 计数/边界处理 → 保持
```

`load` 可直接覆盖当前计数状态，适用于运行时重装初值；`sync_clr` 提供与业务时钟对齐的清零能力；`en` 仅控制是否执行计数，不影响更高优先级控制。

### 3.7 状态流转示例

```text
回绕模式，递增：0 → 1 → ... → MAX → 0 → 1 → ...
回绕模式，递减：MAX → ... → 1 → 0 → MAX → ...

锁存模式，递增：... → MAX-1 → MAX → MAX → ...
                                      │
                                      └─ dir 反转后 → MAX-1 → ...

锁存模式，递减：... → 1 → 0 → 0 → ...
                               │
                               └─ dir 反转后 → 1 → ...
```

任意非复位状态均可通过 `load` 跳转到 `init_val`，或通过 `sync_clr` 在时钟沿回到 0。

## 4. 配置参数

| 参数          | 配置范围 | 默认值 | 描述                                         |
| ------------- | -------- | ------ | -------------------------------------------- |
| WIDTH         | ≥ 2     | 8      | 计数器位宽，决定`q` 和 `init_val` 的宽度 |
| OVERFLOW_WRAP | 0 / 1    | 1      | 1：边界回绕；0：边界锁存                     |

### 4.1 参数配置说明

- `WIDTH=8`：适合多数通用定时、事件计数和控制类场景。
- `OVERFLOW_WRAP=1`：默认采用循环计数行为。
- `OVERFLOW_WRAP=0`：适合队列深度、重传上限等不能允许数值越界的场景。
- 随 `WIDTH` 增加，RCA 传播链同步增长，必须重新评估目标时钟约束。

## 5. 接口

| 信号名   | 位宽  | I/O | 时钟域 | 描述                                                      |
| -------- | ----- | --- | ------ | --------------------------------------------------------- |
| clk      | 1     | I   | clk    | 模块工作时钟，上升沿采样同步控制信号                      |
| rst_n    | 1     | I   | clk    | 同步复位，低有效；在`clk` 上升沿采样                    |
| en       | 1     | I   | clk    | 计数使能；高有效                                          |
| dir      | 1     | I   | clk    | 计数方向；0：递增，1：递减                                |
| load     | 1     | I   | clk    | 动态置数使能；高有效，优先级高于同步清零和计数            |
| init_val | WIDTH | I   | clk    | 动态置数值                                                |
| sync_clr | 1     | I   | clk    | 同步清零；高有效                                          |
| q        | WIDTH | O   | clk    | 当前计数值，寄存器输出，复位值为 0                        |
| cout     | 1     | O   | clk    | 组合进位/借位指示；回绕模式为边界脉冲，锁存模式为驻留电平 |

### 5.1 输入要求

- `rst_n`、`en`、`dir`、`load`、`init_val` 和 `sync_clr` 应满足相对于 `clk` 上升沿的建立时间和保持时间要求。
- 异步输入应先经过同步器；窄脉冲还应完成脉冲捕获或展宽。
- 多位 `init_val` 若来自其他时钟域，应采用握手、异步 FIFO 或其他能够保证数据一致性的跨时钟域方案，不能只对各位独立同步。

### 5.2 输出说明

- `q` 为寄存器输出，包括复位在内的所有状态变化均只发生在有效时钟边沿。
- `cout` 为组合输出，可能随 `en`、`dir` 或边界状态变化；下游若需要严格对齐时钟的事件，应增加寄存器或边沿检测逻辑。
- 锁存模式下，`cout` 可能持续多个周期，不应无条件当作单周期脉冲使用。

## 6. 时序图

以下时序图以 `WIDTH=4` 为例。数值表示每个时钟上升沿后的 `q`。

### 6.1 同步复位

```text
clk       _/‾\_/‾\_/‾\_/‾\_
rst_n      1   0   0   1
load       0   1   0   0
en         1   1   1   1
q          5   6   0   0   1
                    ↑
              时钟沿采样到 rst_n=0 后清零
```

`rst_n` 在时钟沿之间拉低不会立即改变 `q`；只有时钟上升沿采样到 `rst_n=0` 时才执行复位。复位优先级高于同拍有效的 `load` 和 `en`。

### 6.2 计数使能与保持

```text
clk       _/‾\_/‾\_/‾\_/‾\_/‾\_/‾\_
en         1   1   0   0   1   1
dir        0   0   X   X   0   0
q          0   1   2   2   2   3   4
                        └─────┘
                        en=0，保持
```

### 6.3 动态置数与同步清零

```text
clk       _/‾\_/‾\_/‾\_/‾\_/‾\_
load       0   1   0   0   0
init_val   X   A   X   X   X
sync_clr   0   0   0   1   0
en         1   1   1   1   1
q          2   3   A   B   0   1
                    ↑       ↑
                  load   sync_clr
```

当 `load` 与 `sync_clr` 同时为 1 时，`load` 优先，`q` 装载 `init_val`。

### 6.4 递增回绕

```text
clk       _/‾\_/‾\_/‾\_/‾\_
en         1   1   1   1
dir        0   0   0   0
q          D   E   F   0   1
cout       0   0   1   0   0
```

`q=F` 且继续递增时，`cout` 拉高；下一时钟沿 `q` 回绕到 0。

### 6.5 递减回绕

```text
clk       _/‾\_/‾\_/‾\_/‾\_
en         1   1   1   1
dir        1   1   1   1
q          2   1   0   F   E
cout       0   0   1   0   0
```

### 6.6 边界锁存与方向反转

```text
clk       _/‾\_/‾\_/‾\_/‾\_/‾\_
en         1   1   1   1   1
dir        0   0   0   1   1
q          E   F   F   F   E   D
cout       0   1   1   0   0   0
                    └─方向反转后离开上边界
```

## 7. PPA

### 7.1 配置A：8 bit 回绕计数

**参数设置：**

| 参数          | 设置值 | 说明           |
| ------------- | ------ | -------------- |
| WIDTH         | 8      | 通用小位宽计数 |
| OVERFLOW_WRAP | 1      | 边界回绕       |

**PPA 数据：**

| 项目         | 数值                        |
| ------------ | --------------------------- |

### 7.4 综合条件与时序说明

主要时序路径如下：

- 计数反馈路径：`q_reg/Q → RCA 进位/借位链 → 边界选择逻辑 → 控制 MUX → q_reg/D`。
- 动态置数路径：`init_val → 控制 MUX → q_reg/D`。
- 控制路径：`rst_n`、`load`、`sync_clr`、`en` 和 `dir` 到寄存器输入。
- 边界输出路径：`q_reg/Q → 边界比较 → cout`。
- `rst_n` 按普通同步输入进行时序约束。

三组配置均生成了完整的 `check_design`、`check_timing`、QoR、面积、资源、约束、最大/最小时序、功耗和映射网表报告。综合约束为：时钟不确定度 0.050 ns，输入延迟 0.100 ns，输出延迟 0.100 ns，输入转换时间 0.050 ns，输出负载 0.010 pF。三组均无时序、最大转换、最大电容或最大扇出违例，且无宏或黑盒。

功耗报告中的主输入和时序单元输出未标注真实活动，因此动态和漏电功耗仅用于早期比较，不用于产品承诺或签核。
