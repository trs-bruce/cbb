## 1. 功能及应用场景

### 1.1 核心功能 — DS.CBB_CNT_MOD.FUNC.001

支持任意非 `2^N` 模数的同步循环计数器。产品描述中的“非 `2^N` 模数”沿用原始规格写法，其中指数位置的 `N` 表示二进制计数位数这一概念；为避免与后文“计数上限值 N”混淆，本文统一约定：

- `WIDTH`：计数器数据位宽，对应产品描述中 `2^N` 里的位数概念；
- `N`：产品描述中的计数上限配置值/有效模数；
- 因此本文所述“任意非 `2^N` 模数”统一解释为：有效模数 `N` 不要求等于 `2^WIDTH`；
- 实际计数终值为 `N-1`，计数区间为 `0 ~ N-1`。

模块支持两种 N 的配置方式：

- **静态参数配置**：通过参数 `MOD_VAL` 固定 N；
- **运行时动态配置**：通过输入端口 `mod_val` 在运行过程中改变 N。

内部由增量计数逻辑、阈值比较器及复位选择逻辑组成。当当前计数值达到设定终值 `N-1` 时，下一有效时钟沿自动清零到 0，实现循环回绕。

> 说明：`MOD_VAL=0` 仅作为“选择运行时端口配置模式”的模式编码，不表示有效模数 N=0；运行时 `mod_val` 必须配置为合法模数。

### 1.2 应用场景

| 场景         | 说明                                                                     |
| ------------ | ------------------------------------------------------------------------ |
| 非标时钟分频 | 通过任意模数 N 产生非 2 的整数次幂周期计数，可作为任意分频逻辑的计数核心 |
| 波特率发生器 | 根据系统时钟与目标波特率配置 N，周期性产生定时边界                       |
| 任意周期定时 | 计满 N 个时钟周期后自动回绕，形成固定周期定时基准                        |
| 协议定长计数 | 用于固定帧长、包长、符号数、Beat 数等长度计数                            |

## 2. 规格

| DS编号                  | 类型 | 简述                                                                      |
| ----------------------- | ---- | ------------------------------------------------------------------------- |
| DS.CBB_CNT_MOD.FUNC.001 | FUNC | 同步循环计数：有效模数为 N 时，计数值在`0..N-1` 间循环。                |
| DS.CBB_CNT_MOD.FUNC.002 | FUNC | 静态配置：通过参数`MOD_VAL` 配置计数上限值 N。                          |
| DS.CBB_CNT_MOD.FUNC.003 | FUNC | 动态配置：运行时通过端口`mod_val` 动态配置计数上限值 N。                |
| DS.CBB_CNT_MOD.FUNC.004 | FUNC | 阈值比较：内部比较当前计数值与`N-1`，生成边界判定。                     |
| DS.CBB_CNT_MOD.FUNC.005 | FUNC | 自动清零回绕：达到设定终值后，下一有效时钟沿自动回到 0。                  |
| DS.CBB_CNT_MOD.FUNC.006 | FUNC | 运行时阈值更新：动态模式下`mod_val` 改变后，阈值比较逻辑按新的 N 生效。 |

### 2.1 计数区间与回绕 — DS.CBB_CNT_MOD.FUNC.001

当有效模数为 N 时：

| 有效模数 | 计数区间    | 回绕行为                                 |
| -------- | ----------- | ---------------------------------------- |
| `N`    | `0 ~ N-1` | 计到`N-1` 后，下一有效时钟沿回到 `0` |

状态序列为：

```text
0 -> 1 -> 2 -> ... -> N-2 -> N-1 -> 0 -> 1 -> ...
```

本模块为同步循环计数器，正常计数状态仅在 `clk` 有效边沿更新。

### 2.2 静态参数配置 — DS.CBB_CNT_MOD.FUNC.002

静态模式通过参数 `MOD_VAL` 配置 N：

| MOD_VAL | 工作模式       | 有效模数 N 来源  | 说明                                                                  |
| ------- | -------------- | ---------------- | --------------------------------------------------------------------- |
| `0`   | 运行时动态模式 | `mod_val` 端口 | `MOD_VAL=0` 为模式选择编码，不表示 N=0                              |
| `>0`  | 静态参数模式   | `MOD_VAL` 参数 | 模数在 elaboration/综合阶段固定，运行时`mod_val` 不参与计数边界判定 |

静态模式适用于分频比、定时周期或协议长度固定的场景。

### 2.3 运行时动态配置 — DS.CBB_CNT_MOD.FUNC.003

当 `MOD_VAL=0` 时，模块使用运行时端口 `mod_val` 作为有效模数 N。`mod_val` 可在运行过程中更新，从而改变计数终值 `N-1`。

动态模式适用于：

- 可编程分频；
- 可编程波特率；
- 可变周期定时；
- 可变协议长度计数。

### 2.4 阈值比较器 — DS.CBB_CNT_MOD.FUNC.004

内部阈值定义为：

```text
threshold = N - 1
```

边界判定采用：

```text
at_top = (q >= threshold)
```

在正常计数过程中，`q` 依次递增并在 `q == N-1` 时触发回绕。

采用 `>=` 比较可兼容运行时动态修改 N 的情况：若动态减小 N 后当前 `q` 已高于新的终值，则下一有效时钟沿按新的边界规则清零到 0。该行为属于动态阈值配置的实现规则，不改变基本的 `0 ~ N-1` 循环计数语义。

### 2.5 复位选择与自动清零回绕 — DS.CBB_CNT_MOD.FUNC.005

产品描述中的“复位选择逻辑”特指计数达到设定上限后的**内部清零回绕选择逻辑**，即在“正常递增值”和“清零值 0”之间选择下一计数状态；它不等同于模块初始化所使用的外部复位端口 `rst_n`。

内部选择关系为：

```text
next_q = at_top ? 0 : (q + 1)
```

当：

```text
q < N-1
```

下一拍：

```text
q <= q + 1
```

当：

```text
q >= N-1
```

下一拍：

```text
q <= 0
```

因此模块无需依赖自然二进制溢出即可实现任意模数循环。

### 2.6 运行时阈值更新 — DS.CBB_CNT_MOD.FUNC.006

动态模式下，`mod_val` 改变后新的终值为：

```text
new_threshold = mod_val - 1
```

典型情况如下：

| 当前 q 与新终值关系    | 后续行为                                     |
| ---------------------- | -------------------------------------------- |
| `q < new_threshold`  | 按新阈值继续递增                             |
| `q == new_threshold` | 下一有效时钟沿清零回绕                       |
| `q > new_threshold`  | 下一有效时钟沿清零回绕，使计数重新进入新范围 |

> 动态 `mod_val` 应满足模块规定的合法模数范围，并在 `clk` 域内满足输入时序要求。上述 `q > new_threshold` 时下一拍回 0 的处理仅用于动态阈值切换后的合法状态收敛，属于实现规则，不增加新的外部工作模式，也不扩展产品描述的功能边界。

## 3. 方案分析

### 3.1 原理

任意模数同步循环计数器可分解为：

```text
寄存器 + 增量加法器 + 阈值比较器 + 复位选择 MUX
```

结构示意：

```text
                 有效模数 N
                     |
                     v
              +--------------+
              | threshold=N-1|
              +------+-------+
                     |
                     v
q_reg --------> +----------+
                | q >= thr |
                +----+-----+
                     | at_top
                     v
                  +-----+
0 ---------------->|     |
q_reg + 1 -------->| MUX |----> next_q ----> q_reg ----> q
                  +-----+
```

所有计数状态均由统一 `clk` 驱动，因此属于同步计数结构。

### 3.2 阈值比较器实现

静态参数模式：

```text
N = MOD_VAL
threshold = MOD_VAL - 1
```

运行时动态模式：

```text
N = mod_val
threshold = mod_val - 1
```

统一边界判定：

```text
at_top = (q_reg >= threshold)
```

阈值比较器决定计数器是否进入自动清零回绕路径。

### 3.3 多种实现方法对比

| 方案                                        | 关键逻辑              | 任意模数支持        | 动态阈值支持 | 特点                                |
| ------------------------------------------- | --------------------- | ------------------- | ------------ | ----------------------------------- |
| **阈值比较 + 复位选择 MUX（本模块）** | 加法器 + 比较器 + MUX | 支持                | 支持         | 结构直接、通用性强                  |
| 自然二进制溢出                              | 加法器                | 主要适合`2^WIDTH` | 不适合       | 无法直接满足任意非 2 的整数次幂模数 |
| 状态机枚举                                  | 状态译码              | 可支持固定模数      | 灵活性较差   | 状态数增大后维护与面积开销上升      |
| 预置值减法计数                              | 减法器 + 零检测       | 支持                | 支持         | 与本方案计数方向不同，功能等价      |

### 3.4 选定方法

本模块采用“阈值比较 + 复位选择 MUX”方案。

正常路径：

```text
q_reg -> q_reg + 1 -> MUX -> q_reg
```

边界路径：

```text
q_reg -> threshold compare -> MUX -> 0 -> q_reg
```

该方案能够直接实现产品描述要求的：

- `0 ~ N-1` 同步循环计数；
- 静态参数 N；
- 运行时动态 N；
- 到达设定终值自动清零回绕。

### 3.5 详细设计

- 有效模数选择：`MOD_VAL>0` 时使用静态参数；`MOD_VAL=0` 时使用 `mod_val`；
- 阈值生成：`threshold = N - 1`；
- 边界检测：`at_top = (q_reg >= threshold)`；
- 正常递增：`q_reg + 1`；
- 回绕选择：`at_top=1` 时 `next_q=0`；
- 状态更新：`q_reg` 在 `clk` 有效边沿装载 `next_q`。

### 3.6 状态转移图

```text
      +----+     +----+            +---------+
 ---> | S0 | --> | S1 | --> ... -->| S(N-1)  |
      +----+     +----+            +----+----+
        ^                              |
        |______________________________|
                 wrap to 0
```

其中：

```text
S_i 表示 q = i
```

状态转移规则：

| 转移               | 条件                         | 说明                       |
| ------------------ | ---------------------------- | -------------------------- |
| `S_i -> S_(i+1)` | `i < N-1`                  | 正常递增                   |
| `S_(N-1) -> S_0` | 达到终值                     | 自动清零回绕               |
| `S_i -> S_0`     | 动态改小 N 后`i > new_N-1` | 下一有效时钟沿按新阈值回绕 |

## 4. 配置参数

| 参数    | 配置范围                    | 默认值 | 描述                                          |
| ------- | --------------------------- | ------ | --------------------------------------------- |
| WIDTH   | `>=2`，上限由实现约束确定 | 8      | 计数值及动态模数端口位宽                      |
| MOD_VAL | `0` 或合法静态模数 N      | 0      | `0`=运行时动态配置模式；`>0`=静态参数模式 |

### 4.1 参数说明

- `WIDTH` 决定 `q` 与 `mod_val` 的位宽；
- `MOD_VAL=0` 仅用于选择运行时端口模式；
- `MOD_VAL>0` 时，N 由 `MOD_VAL` 固定；
- 运行时模式下，N 由 `mod_val` 提供；
- 有效模数必须能够由 WIDTH 位无符号数表示；
- 产品核心应用面向产品描述中的非 `2^N` 模数场景；在本文统一记法下，即有效模数 `N` 不要求等于 `2^WIDTH`。

## 5. 接口

| 信号名  | 位宽  | I/O | 时钟域 | 类型           | 默认值/复位值 | 描述                                                                           |
| ------- | ----- | --- | ------ | -------------- | ------------- | ------------------------------------------------------------------------------ |
| clk     | 1     | I   | clk    | 时钟           | -             | 同步计数时钟                                                                   |
| rst_n   | 1     | I   | clk    | 同步低有效复位 | -             | 在`clk` 有效边沿采样；用于初始化计数状态，不属于产品描述中的“复位选择逻辑” |
| mod_val | WIDTH | I   | clk    | 数据           | -             | 运行时动态模数 N；仅`MOD_VAL=0` 时参与边界计算                               |
| q       | WIDTH | O   | clk    | 寄存输出       | 0             | 当前计数值，正常有效范围为`0 ~ N-1`                                          |

### 5.1 接口行为说明

- 静态模式：`MOD_VAL>0`，`mod_val` 不参与有效模数计算；
- 动态模式：`MOD_VAL=0`，每次阈值计算使用当前 `mod_val`；
- `q` 仅在 `clk` 有效边沿更新；
- 在 `clk` 有效边沿采样到 `rst_n=0` 时，`q` 更新为 0；
- 到达 `N-1` 后，`q` 在下一有效时钟沿自动变为 0。

### 5.2 同步复位行为

`rst_n` 为同步低有效初始化复位，其优先级高于正常计数和自动回绕：

| `clk` 有效边沿采样值 | `q` 的更新行为                     |
| ---------------------- | ------------------------------------ |
| `rst_n=0`            | `q <= 0`                           |
| `rst_n=1`            | 按当前有效模数执行正常递增或自动回绕 |

`rst_n` 在两个有效边沿之间发生变化时不会直接改变 `q`；只有在 `clk` 有效边沿被采样后才影响计数状态。因此，初始化复位与正常计数均属于统一时钟驱动的同步时序行为。

### 5.3 运行时端口约束

动态配置模式下：

- `mod_val` 必须为合法模数；
- `mod_val` 应在 `clk` 域内满足 setup/hold 要求；
- 若 `mod_val` 来自异步时钟域，应在集成层完成跨时钟域处理后再送入本模块。

## 6. 时序图

### 6.1 静态模数 N=10

```text
clk      _|‾|_|‾|_|‾|_|‾|_|‾|_|‾|_|‾|_|‾|_|‾|_|‾|_|‾|_
q        00 01 02 03 04 05 06 07 08 09 00 01 02 ...
                                            ^
                                            到达 N-1=9，下一拍回 0
```

### 6.2 静态参数模式

```text
MOD_VAL  = 7
mod_val  = XX   （静态模式下不参与边界计算）

q        00 01 02 03 04 05 06 00 01 02 ...
```

计数区间：

```text
0 ~ 6
```

### 6.3 运行时动态阈值增大

```text
mod_val  05 05 05 08 08 08 08 08 ...
q        00 01 02 03 04 05 06 07 00 ...
```

模数从 5 改为 8 后，新的计数区间变为 `0 ~ 7`。

### 6.4 运行时动态阈值减小

例如当前计数值为 8，模数由 10 改为 5：

| `clk` 有效边沿      | E0 | E1 | E2 | E3 |
| --------------------- | -- | -- | -- | -- |
| 边沿采样的`mod_val` | 10 | 5  | 5  | 5  |
| 边沿前的`q`         | 7  | 8  | 0  | 1  |
| 边沿后的`q`         | 8  | 0  | 1  | 2  |

在 E1 到来前，`mod_val=5` 已满足相对于该边沿的输入时序要求。E1 采样新的有效模数后，终值变为 4；此时边沿前的 `q=8` 满足 `q >= 4`，因此 E1 完成状态更新后 `q=0`。后续计数从 0 开始，并在新的 `0 ~ 4` 范围内循环。

该行为由：

```text
q >= (N-1)
```

边界判定实现。该越界回绕在采样到新模数的有效边沿完成状态更新，是运行时动态阈值减小时的状态收敛规则，不构成独立产品功能。
