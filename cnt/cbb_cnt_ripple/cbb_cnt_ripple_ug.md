## 1. 功能及应用场景

### 1.1 功能简介

`CBB_CNT_RIPPLE` 是参数化 N 位纯异步逐次级联计数器（Asynchronous Ripple Counter）。模块仅在最低位设置外部计数时钟入口：

- 第 0 级在外部计数时钟 `clk` 的上升沿翻转；
- 第 i 级（i ≥ 1）由低一位 `q[i-1]` 的下降沿触发翻转；
- 低位输出逐级作为高位的本地触发时钟，不使用一个全局同步时钟同时驱动所有计数级；
- 所有级采用异步低有效复位，复位后计数值为 0；
- 输出 `q` 直接反映各级触发器状态，计数跃迁期间可能短暂出现纹波中间态。

该结构不包含二进制加法器、进位选择器等计数数据通路，逻辑和时钟负载极简。各位平均翻转率随位次指数下降，因此适合对功耗敏感、计数速率较低且不要求多位输出同时稳定的应用。

> **“无全局同步时钟”说明**：本模块仍需要 `clk` 作为外部计数事件输入，但 `clk` 只驱动第 0 级，不扇出到全部 N 级触发器。后续各级由低位输出边沿异步触发。

### 1.2 典型应用场景

| 场景                  | 适用原因                                     |
| --------------------- | -------------------------------------------- |
| 低功耗二进制分频      | 各位天然提供`2^(i+1)` 分频，且高位翻转率低 |
| RTC、看门狗、慢速定时 | 计数速率较低，可为纹波传播预留充足稳定时间   |
| 唤醒计数和事件累计    | 结构简单，外部计数时钟只驱动最低位           |
| 教学和基础电路研究    | 结构直接体现异步纹波计数器的逐级触发原理     |

### 1.3 不适用场景

本模块不适用于以下场景：

- 要求 N 位输出在同一个时钟边沿同时更新；
- 需要对多位计数值进行精准同步采样、比较或译码；
- 高速闭环控制、严格单周期时序或同步时序收敛；
- 不能容忍计数跃迁期间组合译码毛刺的控制逻辑；
- 需要同步加减、并行装载、计数使能或复杂计数模式的场景。

上述场景应优先采用同步二进制计数器；跨时钟域读取完整计数值时，应在系统层增加快照、握手或其他保证总线一致性的机制。

## 2. 规格

| DS编号                     | 类型 | 简述                                                    |
| -------------------------- | ---- | ------------------------------------------------------- |
| DS.CBB_CNT_RIPPLE.INTF.001 | INTF | 输出为各级 T 触发器的异步纹波状态，稳定后表示完整计数值 |
| DS.CBB_CNT_RIPPLE.CFG.001  | CFG  | 通过`WIDTH` 配置计数位宽和级联级数                    |
| DS.CBB_CNT_RIPPLE.FUNC.001 | FUNC | 采用低位输出下降沿逐级触发高位，实现异步二进制加法计数  |
| DS.CBB_CNT_RIPPLE.FUNC.002 | FUNC | 仅支持加法计数                                          |
| DS.CBB_CNT_RIPPLE.FUNC.003 | FUNC | 达到最大值后通过逐级传播自然回绕到 0                    |
| DS.CBB_CNT_RIPPLE.FUNC.004 | FUNC | 支持低有效异步复位，复位后计数值为 0                    |
| DS.CBB_CNT_RIPPLE.PERF.001 | PERF | 最坏纹波稳定时间随位宽近似线性增加                      |

### 2.1 纹波输出 — DS.CBB_CNT_RIPPLE.INTF.001

`q` 为各级 T 触发器输出的直接组合，不经过统一时钟重定时：

- 稳定后，`q` 表示正确的二进制计数值；
- 发生多位翻转时，各位按级联顺序更新；
- 传播过程中可能短暂出现不属于相邻稳定计数值的中间码；
- `q` 不应被视为同一同步时钟域内的原子多位数据。

仅对某个单独分频位进行跨时钟域采样时，可将该位作为普通异步单比特信号处理。若需要读取完整计数值，不能仅对各位分别使用 2～3 级同步器，因为各位独立同步仍不能保证多位数据一致。

### 2.2 位宽配置 — DS.CBB_CNT_RIPPLE.CFG.001

`WIDTH` 决定计数位宽和 T 触发器级数，取值必须不小于 2。位宽越大，计数范围越大，但纹波稳定时间、复位负载以及物理实现难度也随之增加。

### 2.3 异步逐次级联计数 — DS.CBB_CNT_RIPPLE.FUNC.001

模块实现 N 位二进制加法计数：

- 第 0 级 T 触发器由 `clk` 上升沿触发，每次触发后翻转；
- 第 i 级 T 触发器由 `q[i-1]` 的下降沿触发，每次触发后翻转；
- 除第 0 级外，各计数级不接收全局同步时钟；
- 计数序列在输出充分稳定后表现为 `0 → 1 → 2 → ... → 2^WIDTH-1 → 0`。

### 2.4 计数方向 — DS.CBB_CNT_RIPPLE.FUNC.002

模块仅支持加法计数（Up-Counting），不支持减法、方向切换、并行装载和计数暂停。

### 2.5 自然回绕 — DS.CBB_CNT_RIPPLE.FUNC.003

当稳定计数值为 `2^WIDTH-1` 时，下一个 `clk` 上升沿首先使 `q[0]` 从 1 变为 0。该下降沿继续触发下一位，进而形成逐级传播，最终所有位清零并自然回绕到 0，不需要额外的终值检测或清零逻辑。

### 2.6 异步复位 — DS.CBB_CNT_RIPPLE.FUNC.004

`rst_n` 为异步低有效复位：

- `rst_n = 0` 时，所有计数级立即清零，与 `clk` 无关；
- 复位期间 `q = 0`；
- 释放复位后，从 0 开始响应后续 `clk` 上升沿。

系统集成时应保证复位释放满足触发器恢复/移除时间要求。推荐在外部计数时钟停止或保持于稳定电平时释放复位，再启动计数时钟。

### 2.7 纹波传播时间 — DS.CBB_CNT_RIPPLE.PERF.001

最坏情况下，计数变化从最低位逐级传播至最高位。全链稳定时间近似为：

```text
T_ripple(max) ≈ WIDTH × T_clk_to_q(max) + T_skew_margin
```

其中 `T_clk_to_q(max)` 为单级触发器在目标工艺、电压和温度条件下的最大时钟到输出延迟，`T_skew_margin` 为布线偏差、时钟转换和分析裕量。

位宽增加时，传播级数和最坏稳定时间近似线性增加。由于各位并非在同一时刻更新，本模块无法像同步计数器一样对完整多位输出建立统一、精准的单周期同步时序收敛目标。

## 3. 方案分析

### 3.1 工作原理

异步纹波计数器由 N 个翻转触发器级联组成。外部计数时钟只连接最低位，后级使用前一级输出的下降沿作为本级触发事件：

```text
                外部计数时钟       q[0]↓             q[1]↓             q[2]↓
                     │                │                 │                 │
                     ▼                ▼                 ▼                 ▼
                ┌────────┐       ┌────────┐        ┌────────┐        ┌────────┐
                │ T-FF 0 │──────▶│ T-FF 1 │───────▶│ T-FF 2 │───────▶│ T-FF 3 │── ...
                └────────┘       └────────┘        └────────┘        └────────┘
                     │                │                 │                 │
                   q[0]             q[1]              q[2]              q[3]
                     └────────────────┴─────────────────┴─────────────────┘
                                             q

                rst_n 异步复位所有级
```

若每级均在输入下降沿翻转，则第 i 位的稳态翻转频率为外部计数时钟的 `1/2^(i+1)`。随着位次升高，触发频率快速下降，使总平均翻转活动接近常数，而不会随位宽线性增长。

### 3.2 主流实现方案对比

| 方案                | 时钟方式                       | 多位输出更新     | 逻辑复杂度 | 功耗特征 | 适用场景               |
| ------------------- | ------------------------------ | ---------------- | ---------- | -------- | ---------------------- |
| 异步 T-FF 纹波级联  | 仅首级接外部时钟，后级逐次触发 | 不同时，存在纹波 | 极低       | 极低     | 低速、低功耗分频和累计 |
| 同步二进制计数器    | 全部触发器共享全局时钟         | 同一时钟边沿更新 | 中         | 中       | 通用同步计数和精确采样 |
| 预定标加同步计数    | 低位预分频，高位同步计数       | 分段同步         | 中         | 低至中   | 宽位、高输入频率       |
| 环形/Johnson 计数器 | 全部触发器共享全局时钟         | 同一时钟边沿更新 | 低         | 低       | 非二进制状态序列       |

### 3.3 选定方案

本模块采用异步 T-FF 纹波级联，原因如下：

- 结构极简，每级只需保存并翻转一个状态位；
- 外部计数时钟不需要驱动全部 N 级触发器，降低全局时钟扇出和时钟树动态功耗；
- 不需要加法器、进位链或多路选择器；
- 第 i 位仅按 `1/2^(i+1)` 的输入频率翻转，适合低功耗分频；
- 以多级传播延迟和非同时更新换取面积与功耗优势，符合本产品定位。

### 3.4 T 触发器实现

T 触发器可用 D 触发器反馈实现，等效关系为 `D = ~Q`：

- 第 0 级行为：在 `posedge clk` 或 `negedge rst_n` 时更新；
- 第 i 级行为：在 `negedge q[i-1]` 或 `negedge rst_n` 时更新；
- `rst_n = 0` 时优先清零；
- 正常计数时，每次有效触发边沿执行 `q[i] <= ~q[i]`。

低位 Q 作为高位触发时钟属于本架构的基本连接方式。综合、STA、DFT 和物理实现流程必须显式识别这些内部派生时钟，不能按普通同步数据路径处理。

### 3.5 传播与采样约束

一次外部计数事件可能仅翻转最低位，也可能触发多级连续翻转。回绕时需要传播全部 WIDTH 级，因此是最坏情况。

系统使用 `q` 时必须遵守以下约束：

1. 在外部计数边沿之后至少等待 `T_ripple(max)`，才可把 `q` 当作稳定计数值读取；
2. 不得在纹波传播窗口内要求 `q` 满足同步总线的建立/保持关系；
3. 不应直接使用 `q` 的组合译码结果产生关键控制脉冲，除非下游允许毛刺；
4. 跨时钟域读取完整 `q` 时，应先冻结或锁存稳定快照，再通过握手传输；
5. 若只使用某一个高位作为分频输出，应按异步单比特 CDC 信号处理；
6. WIDTH 较大或采样时序紧张时，应改用同步计数器或预定标结构。

### 3.6 实现与签核注意事项

- **STA**：为各级派生时钟建立符合工具要求的时钟关系或采用专门的异步路径约束，并单独检查逐级传播上限；
- **CTS**：仅 `clk` 属于外部时钟入口，内部 `q[i]` 到下一级时钟端为功能性派生时钟连接；
- **DFT**：扫描插入和测试模式需要确认内部派生时钟可控、复位可控；
- **CDC/RDC**：`q` 是异步多位总线，`rst_n` 是异步复位，需在系统级完成 CDC/RDC 审查；
- **门级仿真**：应检查真实单元和布线延迟下的纹波顺序、中间态及最坏稳定时间；
- **物理实现**：宜缩短相邻级之间的连接，以降低额外延迟和级间偏差。

| 参数  | 配置范围 | 默认值 | 描述                                                        |
| ----- | -------- | ------ | ----------------------------------------------------------- |
| WIDTH | ≥ 2     | 8      | 计数位宽，同时决定 T 触发器级数、计数范围和最坏纹波传播级数 |

配置建议：

| WIDTH 范围 | 建议                                                             |
| ---------- | ---------------------------------------------------------------- |

> 位宽建议不是功能限制。最终可用范围必须依据目标工艺库、输入计数频率、输出采样方式和 PVT 签核结果确定。

## 5. 接口

### 5.1 接口信号表

| 信号名 | 位宽  | I/O | 时钟域       | 描述                                                         |
| ------ | ----- | --- | ------------ | ------------------------------------------------------------ |
| clk    | 1     | I   | 外部计数时钟 | 仅驱动第 0 级 T-FF；每个上升沿产生一次计数事件               |
| rst_n  | 1     | I   | 异步         | 低有效异步复位，清零所有计数级                               |
| q      | WIDTH | O   | 异步纹波     | 各级 T-FF 直接输出；稳定后表示计数值，传播期间可能出现中间态 |

### 5.2 接口行为

| 条件                                  | `q` 行为                           |
| ------------------------------------- | ------------------------------------ |
| `rst_n = 0`                         | 所有位异步清零，稳定值为 0           |
| `rst_n` 释放、尚无 `clk` 上升沿   | 保持 0                               |
| 每个`clk` 上升沿后                  | 从低位开始逐级传播，稳定后计数值加 1 |
| 稳定值为全 1 后的下一个`clk` 上升沿 | 所有位依次由 1 变为 0，最终回绕到 0  |

### 5.3 外部时序要求

| 约束项             | 要求                                                                  |
| ------------------ | --------------------------------------------------------------------- |
| `clk` 最小周期   | 必须大于最坏纹波稳定时间并包含系统要求的采样裕量；以 PVT 签核结果为准 |
| `clk` 高/低脉宽  | 满足第 0 级触发器的最小脉宽要求                                       |
| `rst_n` 有效脉宽 | 满足所有计数级异步复位最小脉宽要求                                    |
| `rst_n` 释放     | 满足恢复/移除时间；推荐在`clk` 停止或保持稳定时释放                 |
| `q` 稳定采样     | 采样时刻不得早于`clk` 有效沿加最坏纹波稳定时间                      |
| 多位 CDC           | 不允许仅用逐位同步器实现一致计数值传输，应使用稳定快照和握手等机制    |

### 5.4 例化示例

```verilog

  .WIDTH (8)
) U_CBB_CNT_RIPPLE (
  .clk   (clk),
  .rst_n (rst_n),
  .q     (q)
```

### 6.1 正常计数（WIDTH = 4）

下图中的数字表示每次纹波传播完成后的稳定计数值：

```text
clk      __/‾\__/‾\__/‾\__/‾\__/‾\__/‾\__/‾\__/‾\__

q[0]     0___1___0___1___0___1___0___1___0
q[1]     0_______1_______0_______1_______0
q[2]     0_______________1_______________0
q[3]     0_______________________________1

稳定 q   0   1   2   3   4   5   6   7   8
```

每个 `clk` 上升沿首先翻转 `q[0]`。只有当某一级发生 1→0 下降沿时，才触发更高一级翻转。

### 6.2 多级纹波传播（WIDTH = 4，7 → 8）

```text
clk       ________/‾\____________________________
                   ↑

q[0]      ‾‾‾‾‾‾‾‾\____________________________   1 → 0
                     ↓ 触发 q[1]
q[1]      ‾‾‾‾‾‾‾‾‾‾\__________________________   1 → 0
                       ↓ 触发 q[2]
q[2]      ‾‾‾‾‾‾‾‾‾‾‾‾\________________________   1 → 0
                         ↓ 触发 q[3]
q[3]      ________________/‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾   0 → 1

观察值     0111 → 0110 → 0100 → 0000 → 1000
           稳定       纹波中间态          稳定
```

各位不会同时更新。下游若在传播窗口内读取或译码 `q`，可能观察到 `6、4、0` 等中间值。

### 6.4 异步复位

```text
clk       __/‾\__/‾\__/‾\__/‾\__/‾\__/‾\__
rst_n     ‾‾‾‾‾‾‾‾‾‾\__________/‾‾‾‾‾‾‾‾‾‾

```

`rst_n` 拉低后无需等待 `clk` 即可清零；复位释放应满足恢复/移除时间要求。

### 7.3 时钟与纹波时序结果

| WIDTH | 外部时钟周期 | generated clock 数量 | 最高级 generated clock 周期 | setup violation | hold violation |
| ----: | -----------: | -------------------: | --------------------------: | --------------: | -------------: |
|     4 |    10.000 ns |                    3 |                       80 ns |               0 |              0 |
|     8 |    10.000 ns |                    7 |                     1280 ns |               0 |              0 |
|    16 |    10.000 ns |                   15 |                   327680 ns |               0 |              0 |

“最长单级路径”来自各时钟组的 mapped self-feedback path，包含触发器 clk-to-Q 和反相反馈组合路径。它不是完整纹波链稳定时间。

完整 `clk -> q[WIDTH-1]` 纹波稳定时间在本次 DC ZeroWireload 流程中标记为 **NOT CHECKED**。原因是每一级传播跨越独立时序单元且 `q` 为异步输出，不能把它伪装成普通同步 reg-to-reg 路径。最终稳定时间必须由门级 SDF 仿真或布局布线后、包含真实时钟网络和寄生参数的专用 STA 获得。

### 7.4 功耗解释

动态功耗随 WIDTH 增长缓慢，而漏电功耗近似随位宽增加。这与纹波计数器的活动特征一致：低位频繁翻转，高位平均翻转率按位次递减。当前功耗数值只适用于所列库、100 MHz 外部输入和 vectorless 活动假设，不能作为硅后功耗承诺。

### 7.5 与同步计数器的 PPA 定性对比

| 对比项           | `cbb_cnt_ripple`           | 同步二进制计数器             |
| ---------------- | ---------------------------- | ---------------------------- |
| 全局时钟负载     | 只驱动第 0 级                | 驱动全部计数触发器           |
| 组合计数逻辑     | 极少                         | 需要加法/进位逻辑            |
| 平均翻转活动     | 低，高位指数递减             | 时钟端每拍均有活动           |
| 多位输出一致性   | 存在纹波，非同时更新         | 同一时钟边沿更新             |
| 延迟随位宽变化   | 逐级累计，近似线性恶化       | 取决于同步进位结构           |
| 精准同步时序收敛 | 不适合                       | 适合                         |
| 主要优势         | 面积小、时钟负载低、功耗极低 | 输出同步、易于系统集成和签核 |
