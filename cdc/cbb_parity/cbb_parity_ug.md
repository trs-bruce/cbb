## 1. 功能及应用场景

`CBB_PARITY` 是一个参数化的奇偶校验生成电路（Parity Generator），用于对输入数据字计算奇偶校验位。该 CBB 为纯组合逻辑，无时钟、无复位，可直接嵌入数据通路或作为更大校验逻辑的一部分。

**核心功能：**

- 对 `DATA_WIDTH` 位输入数据 `datain` 计算奇偶校验结果；
- 支持偶校验（even）与奇校验（odd），通过参数 `PAR_TYPE` 静态选择；
- 输出 `parity` 为 1 位，反映输入数据是否符合所选校验类型。

**典型应用场景：**

- DRAM/SRAM 数据通路的奇偶校验位生成；
- UART、磁盘驱动器等低速串行/并行通信传输字的校验位计算；
- 存储或传输链路中接收端本地重算校验值，与随路校验位比对以检测错误。

## 2. 规格

每条规格以 DS 点编号标识，命名规则为 `DS.[IP_NAME].[TYPE][SPEC_ID]`。本 CBB 规格编号如下：

| DS 点编号                 | 类型  | 名称               | 简要描述                                          |
|---------------------------|-------|--------------------|---------------------------------------------------|
| DS.CBB_PARITY.FUNC.001    | FUNC  | 奇偶校验生成功能   | 对 `datain` 所有位归约，生成 1 位 `parity`   |
| DS.CBB_PARITY.FUNC.002    | FUNC  | 偶校验支持         | `PAR_TYPE = 0` 时，XNOR 归约                      |
| DS.CBB_PARITY.FUNC.003    | FUNC  | 奇校验支持         | `PAR_TYPE = 1` 时，XOR 归约                       |
| DS.CBB_PARITY.CFG.001     | CFG   | 位宽可配置         | `DATA_WIDTH` 支持 1 ~ 256                         |
| DS.CBB_PARITY.CFG.002     | CFG   | 校验类型可配置     | `PAR_TYPE` 选择偶校验/奇校验                      |
| DS.CBB_PARITY.INTF.001    | INTF  | 输入接口           | `datain` 为 `DATA_WIDTH` 位输入数据总线         |
| DS.CBB_PARITY.INTF.002    | INTF  | 输出接口           | `parity` 为 1 位校验结果输出                    |
| DS.CBB_PARITY.PERF.001    | PERF  | 纯组合逻辑         | 无时钟、无复位、无使能                            |

### 2.1 奇偶校验生成功能 — DS.CBB_PARITY.FUNC.001

`CBB_PARITY` 对输入数据字 `datain` 的所有位进行归约运算，生成 1 位奇偶校验结果 `parity`。

### 2.2 偶校验支持 — DS.CBB_PARITY.FUNC.002

当 `PAR_TYPE = 1'b0` 时，组件工作于偶校验模式。输出逻辑等效为：

```verilog
parity = ~(^datain);
```

即输入数据中 1 的个数为偶数时输出 `1'b1`，为奇数时输出 `1'b0`。

### 2.3 奇校验支持 — DS.CBB_PARITY.FUNC.003

当 `PAR_TYPE = 1'b1` 时，组件工作于奇校验模式。输出逻辑等效为：

```verilog
parity = ^datain;
```

即输入数据中 1 的个数为奇数时输出 `1'b1`，为偶数时输出 `1'b0`。

### 2.4 位宽可配置 — DS.CBB_PARITY.CFG.001

输入数据位宽由参数 `DATA_WIDTH` 配置，默认值为 8，支持范围为 1 至 256。位宽在综合期静态确定，不可运行时切换。

### 2.5 校验类型可配置 — DS.CBB_PARITY.CFG.002

校验类型由参数 `PAR_TYPE` 配置：`1'b0` 表示偶校验，`1'b1` 表示奇校验。该参数在综合期静态确定，不可运行时切换。

### 2.6 输入接口 — DS.CBB_PARITY.INTF.001

`datain` 为 `DATA_WIDTH` 位输入数据总线，携带待计算奇偶校验位的数据字。

### 2.7 输出接口 — DS.CBB_PARITY.INTF.002

`parity` 为 1 位输出，表示输入数据在当前校验类型下的奇偶校验结果。

### 2.8 纯组合逻辑 — DS.CBB_PARITY.PERF.001

`CBB_PARITY` 为纯组合逻辑设计，无时钟、无复位、无使能。输出到输入的组合逻辑路径为 XOR/XNOR 归约树，逻辑级数随位宽对数增长。

## 3. 方案分析

### 3.1 原理分析

奇偶校验是最简单的错误检测码，通过对数据位进行 XOR/XNOR 归约得到 1 位校验信息：

- **偶校验**：要求数据位与校验位中 1 的总数为偶数。本 CBB 输出的是“输入数据本身是否符合偶性”的指示，因此采用 XNOR 归约：
  - 输入中 1 的个数为偶数 → 输出 `1'b1`；
  - 输入中 1 的个数为奇数 → 输出 `1'b0`。

- **奇校验**：要求数据位与校验位中 1 的总数为奇数。本 CBB 输出的是“输入数据本身是否符合奇性”的指示，因此采用 XOR 归约：
  - 输入中 1 的个数为奇数 → 输出 `1'b1`；
  - 输入中 1 的个数为偶数 → 输出 `1'b0`。

> **极性约定说明**：本 CBB 的输出极性与“在数据后附加校验位使整体 1 的个数为偶/奇”的经典校验位定义相反。若需与外部协议（如 UART）对接，应在系统级验证极性是否需取反。

### 3.2 设计方案

1. **参数静态选择校验类型**：通过 `PAR_TYPE` 参数在综合期选择 XOR 或 XNOR 归约，避免运行时多路选择器开销。
2. **纯组合实现**：不使用时钟和复位，直接对输入进行位归约，适合嵌入任意数据通路。
3. **校验器扩展**：本 CBB 仅生成校验结果。若要构成完整 checker，需将 `parity` 与接收到的校验位再做一级 XOR：

   ```verilog
   error = parity ^ parity_bit_received;
   ```

   - `error = 1'b0`：两端一致，校验通过；
   - `error = 1'b1`：校验失配，判定传输出错。

### 3.3 真值表

| `datain` 中 1 的个数 | `PAR_TYPE` | `parity` |
|------------------------|------------|------------|
| 偶数                   | 0（偶校验）| 1          |
| 奇数                   | 0（偶校验）| 0          |
| 偶数                   | 1（奇校验）| 0          |
| 奇数                   | 1（奇校验）| 1          |

## 5. 接口

| 信号名     | 位宽                  | I/O | 时钟域 | 描述                                      |
|------------|-----------------------|-----|--------|-------------------------------------------|
| `datain` | `[DATA_WIDTH-1:0]`    | I   | -      | 输入数据字，待计算奇偶校验位              |
| `parity` | 1                     | O   | -      | 奇偶校验结果输出，组合逻辑输出            |

> 说明：本模块为纯组合逻辑，无时钟和复位信号。

## 6. 时序图

`CBB_PARITY` 为纯组合逻辑，无时钟驱动时序。输入到输出的传播延迟为 XOR/XNOR 归约树延迟，典型路径如下：

```
datain[DATA_WIDTH-1:0]  ──→  XOR/XNOR 归约树  ──→  parity
```

由于无时钟，本章节不适用传统时钟沿对齐时序图。在集成到同步系统时，建议在 `datain` 稳定后采样 `parity`，并在数据变化后预留足够的组合逻辑稳定时间。

### 7.4 时序说明

本模块为纯组合逻辑，输入到输出为 XOR/XNOR 归约树。SDC 约束时钟周期为 0.7 ns（约 1428 MHz），输入/输出延迟比例 0.1（即各预留 0.07 ns），时钟不确定性 ±0.1 ns。三个配置在 SS Corner（0.9V, 125°C）下均满足时序（WNS=0, TNS=0），裕量充足。

关键路径延迟与 `DATA_WIDTH` 呈对数关系（归约树深度 ∝ log₂(DATA_WIDTH)），面积和功耗与位宽近似线性关系。各配置路径延迟远小于时钟周期的 50%，留有充裕的组合逻辑预算供外围寄存器插入。
