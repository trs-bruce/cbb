## 1. 功能及应用场景

### 1.1 核心功能

`CBB_CRC_S` 是通用串行 CRC（Cyclic Redundancy Check，循环冗余校验）生成与校验模块，提供以下核心能力：

- **CRC 生成（发送/存储模式）**：对输入数据流逐段计算 CRC 值，并将 CRC 校验位插入到输出数据流末尾。
- **CRC 校验（接收/读取模式）**：接收包含 CRC 校验位的数据流，验证数据完整性并输出校验结果。
- **上下文切换**：支持保存和恢复内部 CRC 寄存器状态，可在多个数据流间分时共享该模块或交错处理不同事务。

### 1.2 适用场景

| 应用领域 | 典型场景 |
|----------|----------|
| 通信协议 | 以太网帧 CRC-32 生成/校验、HDLC/PPP 帧 CRC 校验 |
| 存储系统 | NAND Flash 页数据 ECC/CRC 保护、SSD 数据路径完整性校验 |
| 总线接口 | PCIe TLP 的 LCRC/ECRC、AXI 数据 CRC 保护 |
| 通用数据保护 | 串行数据流实时 CRC 计算、固件镜像完整性校验 |

### 1.3 关键特性

- 支持最高 64 位任意 CRC 多项式，通过分段系数参数灵活配置
- 参数化数据位宽 `data_width`（1 ~ poly_size），poly_size 必须是 data_width 的整数倍
- 支持全 0 或全 1 的 CRC 寄存器初始化
- 支持 CRC 插入时奇数位/偶数位/全取反/不取反共 4 种翻转模式
- 支持 MSB-first / LSB-first 位序及字节序共 4 种组合
- 支持外部加载 CRC 寄存器值，用于上下文切换和状态恢复
- 纯同步设计，寄存器输出版本 `draining`、`drain_done`、`crc_ok`、`data_out`

## 2. 规格

### 规格汇总

| DS.CRC_S.CFG.001 | CFG | 参数化多项式 |
| DS.CRC_S.CFG.002 | CFG | 参数化数据位宽 |

| DS.CRC_S.CFG.004 | CFG | 位序与字节序配置 |
| DS.CRC_S.INTF.001 | INTF | 控制接口 |
| DS.CRC_S.INTF.002 | INTF | 数据输出行为 (data_out) |

| DS.CRC_S.PERF.001 | PERF | 寄存器输出 |

### 2.1 CRC 生成功能 — DS.CRC_S.FUNC.001

模块应支持 CRC 生成（Transmit/Store）模式，操作流程如下：

1. **初始化**：拉低 `init_n` 至少一个时钟周期，将 CRC 寄存器复位到 `crc_cfg` 定义的初始值。
2. **数据计算**：在 `enable = 1`、`drain = 0` 下逐段输入待发送数据 `data_in`，模块逐周期计算 CRC 中间值，`data_out` 直通 `data_in`，`crc_out` 实时反映当前 CRC 寄存器状态。
3. **排出 CRC**：数据输入完毕后拉高 `drain`，模块停止接收 `data_in`，`draining` 拉高，`data_out` 按位序规则依次输出 CRC 校验位（不再直通 `data_in`）。
4. **排出完成**：CRC 全部排出后，`drain_done` 拉高一拍（单周期脉冲），`draining` 拉低。
5. **重新初始化**：下一次操作前需再次拉低 `init_n` 至少一个周期。

### 2.2 CRC 校验功能 — DS.CRC_S.FUNC.002

模块应支持 CRC 校验（Receive/Retrieve）模式，`drain` 全程保持为 0，操作流程如下：

1. **初始化**：拉低 `init_n` 至少一个时钟周期，将 CRC 寄存器复位到 `crc_cfg` 定义的初始值。
2. **数据计算**：在 `enable = 1`、`drain = 0` 下逐段输入接收到的全部数据（包括发送端附加的 CRC 校验位），模块逐周期计算 CRC 中间值，`crc_out` 实时反映当前 CRC 寄存器状态。
3. **校验判定**：当包含 CRC 校验位的最后一个数据字被时钟打入后，内部 CRC 寄存器收敛到残余值，`crc_ok` 在下一拍更新：若残余值与 `crc_cfg` 定义的预期残余值一致则 `crc_ok = 1`（数据正确），否则 `crc_ok = 0`（数据错误）。
4. **重新初始化**：下一次校验前需再次拉低 `init_n` 至少一个周期。

### 2.3 上下文切换 — DS.CRC_S.FUNC.003

模块应支持通过 `crc_out` 输出端口实时监测内部 CRC 寄存器值，以及通过 `crc_in` + `ld_crc_n` 信号加载外部 CRC 值到内部寄存器，实现上下文保存与恢复。

### 2.4 Stall 停滞功能 — DS.CRC_S.FUNC.004

模块应支持通过 `enable` 信号控制运算的启停。当 `enable = 0` 时，模块进入停滞状态：内部 CRC 寄存器保持当前值不变，`data_out` 保持当前值不变，`draining` 和 `drain_done` 保持当前状态不变，`data_in` 被忽略。当 `enable` 恢复为 1 后，模块从停滞前的状态继续运算。Stall 不影响 `rst_n`（异步复位）和 `init_n`（同步初始化）的执行——二者在 enable=0 时仍有效。

### 2.5 参数化多项式 — DS.CRC_S.CFG.001

模块应支持通过 `poly_coef0` ~ `poly_coef3` 四个 16 位参数配置任意 2~64 位 CRC 多项式。多项式最高次项 x^poly_size 为隐含项，无需在参数中体现。`poly_coef0` 必须是奇数（因为所有本原多项式都包含 x^0 = 1 项）。

### 2.6 参数化数据位宽 — DS.CRC_S.CFG.002

模块应支持通过 `data_width` 参数配置每时钟周期处理的数据位宽，取值范围 1 ~ poly_size，且 poly_size 必须是 data_width 的整数倍。

### 2.7 CRC 初始化与插入配置 — DS.CRC_S.CFG.003

模块应支持通过 `crc_cfg` 参数（0~7）配置 CRC 寄存器初始值（全 0 或全 1）和 CRC 插入时的位翻转方式（不取反/奇数位翻转/偶数位翻转/全取反）。奇数 `crc_cfg` 值表示全 1 初始化，偶数表示全 0 初始化。

| CRC_CFG | CRC 寄存器初始值 | 插入 CRC 位处理方式 |
|---------|-----------------|---------------------|
| 0 | 全 0 | 不取反 |
| 1 | 全 1 | 不取反 |
| 2 | 全 0 | 与 `...010101` 异或（奇数位翻转） |
| 3 | 全 1 | 与 `...010101` 异或（奇数位翻转） |
| 4 | 全 0 | 与 `...101010` 异或（偶数位翻转） |
| 5 | 全 1 | 与 `...101010` 异或（偶数位翻转） |
| 6 | 全 0 | 全部取反 |
| **7** | **全 1** | **全部取反（最常用配置）** |

### 2.8 位序与字节序配置 — DS.CRC_S.CFG.004

模块应支持通过 `bit_order` 参数（0~3）配置数据的比特处理顺序和字节处理顺序，支持 MSB-first / LSB-first 共 4 种组合。当 data_width 不是 8 的倍数时，bit_order 仅支持 0 或 1（不支持字节序调整）。

| BIT_ORDER | CRC 计算位序 | 字节序 | 适用条件 |
|-----------|-------------|--------|----------|
| 0 | MSB first，LSB last | MSB first，LSB last | 无限制 |
| 1 | LSB first，MSB last | LSB first，MSB last | 无限制 |
| 2 | MSB first，LSB last | LSB first，MSB last | DATA_WIDTH 为 8 的倍数 |
| 3 | LSB first，MSB last | MSB first，LSB last | DATA_WIDTH 为 8 的倍数 |

### 2.9 控制接口 — DS.CRC_S.INTF.001

模块应提供完整的控制信号接口：异步复位 `rst_n`（低有效）、同步初始化 `init_n`（低有效）、模块使能 `enable`（高有效）、CRC 排出控制 `drain`（高有效）、CRC 加载控制 `ld_crc_n`（低有效）。

### 2.10 数据输出行为 — DS.CRC_S.INTF.002

`data_out` 的行为应按当前工作模式区分：

1. **CRC 生成模式 — 数据阶段**（`enable = 1`，`drain = 0`）：`data_out` 直通 `data_in`，延迟一拍输出。
2. **CRC 生成模式 — 排出阶段**（`enable = 1`，`drain = 1`）：`data_out` 依次输出 CRC 寄存器值按位序规则产生的 CRC 校验位，不再直通 `data_in`。
3. **CRC 校验模式**（`enable = 1`，`drain = 0`）：`data_out` 直通 `data_in`，延迟一拍输出。
4. **初始化期间**（`init_n = 0`）：`data_out` 输出全 0。
5. **Stall 期间**（`enable = 0`）：`data_out` 保持前一拍的值不变。
6. **复位期间**（`rst_n = 0`）：`data_out` 输出全 0。

### 2.11 CRC 校验结果输出 — DS.CRC_S.INTF.003

`crc_ok` 的行为应按当前工作模式区分：

1. **CRC 校验模式**：`crc_ok` 每周期持续更新，反映当前 CRC 残余值是否与 `crc_cfg` 定义的预期残余值一致（一致则 `crc_ok = 1`，否则为 `0`）。用户应在最后一个 CRC 字被处理后将 `enable` 拉低以冻结 CRC 状态，此时 `crc_ok` 的值即为最终校验结果——该值在 `enable = 0` 期间保持不变，直至下次 `init_n` 清零。
2. **CRC 生成模式**：`crc_ok` 固定输出 0（无效/不使用）。

### 2.12 寄存器输出 — DS.CRC_S.PERF.001

所有输出信号（`draining`、`drain_done`、`crc_ok`、`data_out`、`crc_out`）均应为寄存器输出，确保时序收敛。

## 3. 方案分析

### 3.1 核心原理

CRC 的本质是**多项式除法求余数**。在 GF(2) 伽罗瓦域中，对消息多项式 M(x) 乘以 x^N（N = poly_size）后除以生成多项式 G(x)，所得余数 R(x) 即为 CRC 值。

**发送端**：M(x) · x^N mod G(x) = R(x)，将 R(x) 附加到消息末尾发送。

**接收端**：对收到的完整消息（含 CRC）同样执行除法，若余数为 0 则数据正确。

### 3.2 硬件架构设计

模块采用 **LFSR（线性反馈移位寄存器）+ 并行输入** 架构，分为**数据通路**和**控制通路**两部分：

```
                    ┌─── 控制通路 ──────────────────────────────────────────┐
                    │                                                        │
  rst_n ────────────┤                                                        │
  init_n ───────────┤    ┌──────────────┐                                   │
  enable ───────────┤───>│              │──── draining ─────────────────────>│
  drain  ───────────┤───>│ Control FSM  │──── drain_done ──────────────────>│
  ld_crc_n ─────────┤───>│  (控制状态机) │──── crc_ok ──────────────────────>│
                    │    │              │──── output_sel ──────┐             │
                    │    └──────────────┘                     │             │
                    └──────────────────────────────────────────┼─────────────┘
                                                               │
  ┌─── 数据通路 ───────────────────────────────────────────────┼─────────────┐
  │                                                            │             │
  │  data_in ──>│ Bit Reorder │──>│ CRC Feedback │──>│ Output │──> data_out │
  │     │          (位序重排)        Array(反馈阵列)   │  Mux   │    (寄存器) │
  │     │              │                 │             │        │             │
  │     │         bit_order        poly_coef     output_sel ────┘             │
  │     │                              │                                     │
  │     │                    ┌─────────v─────────┐                           │
  │     │                    │   CRC Register     │──> crc_out (寄存器输出)   │
  │     │                    │   (时序寄存器)      │                           │
  │     │                    └─────────┬─────────┘                           │
  │     │                              │                                     │
  │     │                         feedback ──────────────────> CRC Feedback   │
  │     │                              │                        Array 输入端   │
  │     │                                                                     │
  │     │  crc_in ───────────────────>│ CRC Register (ld_crc_n=0 时加载)      │
  │     │                                                                     │
  │     └── 控制信号到各模块:                                                  │
  │         · rst_n ──> CRC Register (异步复位至 crc_cfg 初始值)               │
  │         · init_n ──> CRC Register (同步复位至 crc_cfg 初始值)              │
  │         · enable ──> CRC Register (写使能, enable=0 时保持)                │
  └───────────────────────────────────────────────────────────────────────────┘
```

### 3.3 并行 LFSR 反馈阵列

由于 data_width 可大于 1，需要在单周期内完成多项式除法的多步迭代。设计采用**组合逻辑展开**方法：

- 将单步 LFSR 反馈逻辑展开为 data_width 级级联组合逻辑
- 每级组合逻辑等效于一个单比特移位 + 反馈操作
- 通过 generate 循环构建 data_width 级反馈阵列

核心反馈方程（以 poly_size = 32 为例）：

```
next_crc[0] = data_in_bit ^ (poly_coef0[0] ? crc[31] : 0)
next_crc[i] = crc[i-1] ^ (poly_coef0[i] ? crc[31] : 0)   (1 ≤ i < poly_size)
```

其中 `crc[31]`（最高位）为反馈移出位，若对应多项式系数为 1 则参与反馈。

### 3.4 位序重排（Bit Reordering）

根据 `bit_order` 参数对输入数据进行位序调整，支持以下四种模式：

| bit_order | 位序 | 字节序 | 处理方式 |
|-----------|------|--------|----------|
| 0 | MSB first | MSB first | 不做重排，原始顺序 |
| 1 | LSB first | LSB first | data_in 整体按位反转 |
| 2 | MSB first | LSB first | 字节内保持不变，字节间反转 |
| 3 | LSB first | MSB first | 字节内按位反转，字节间保持不变 |

当 `data_width` 不是 8 的倍数时，仅支持 bit_order = 0 或 1。

### 3.5 CRC 插入与校验

**CRC 插入（drain 阶段）**：

- `drain` 信号拉高后，模块停止接收 data_in
- 输出 `data_out` 切换为 CRC 寄存器值的移位输出（按位序规则）
- `draining` 拉高，指示正在排出 CRC
- CRC 全部排出后 `drain_done` 拉高，`draining` 拉低

**CRC 校验**：

- 将包含 CRC 校验位的数据全部输入后，内部 CRC 寄存器为残余值
- 若数据正确，残余 CRC 值等于特定预期值（取决于 crc_cfg 配置）
- `crc_ok` 在最后一个数据字被时钟打入后更新

### 3.6 初始化与复位策略

| 信号 | 类型 | 功能 |
|------|------|------|
| `rst_n` | 异步复位 | 上电或全局异常复位，CRC 寄存器恢复为 crc_cfg 定义的初始值 |
| `init_n` | 同步初始化 | 帧级 CRC 状态重置，功能同复位但同步于 clk |
| `ld_crc_n` | 同步加载 | 将 crc_in 值加载到 CRC 寄存器，用于上下文恢复 |

复位/初始化/加载的优先级：`rst_n`（异步） > `init_n`（同步） > `ld_crc_n`（同步加载） > `enable`（正常运算）。

## 4. 配置参数

| 参数 | 取值范围 | 默认值 | 描述 |
|------|----------|--------|------|
| `DATA_WIDTH` | 1 ~ POLY_SIZE | 16 | 每时钟周期处理的数据位宽。POLY_SIZE 必须是 DATA_WIDTH 的整数倍 |

| `POLY_COEF2` | 0 ~ 65535 | 0 | 多项式系数 bits [47:32]，映射多项式 x^32 ~ x^47 项 |
| `POLY_COEF3` | 0 ~ 65535 | 0 | 多项式系数 bits [63:48]，映射多项式 x^48 ~ x^63 项 |

## 5. 接口

### 5.1 信号列表

| 信号名 | 位宽 | I/O | 时钟域 | 描述 |
|--------|------|-----|--------|------|
| `clk` | 1 | I | clk | 模块工作时钟输入 |
| `rst_n` | 1 | I | - | 异步复位输入，低电平有效 |
| `init_n` | 1 | I | clk | 同步初始化输入，低电平有效；功能同复位但与时钟同步 |
| `enable` | 1 | I | clk | 模块使能控制，高电平有效；控制除复位和初始化外的所有操作 |
| `drain` | 1 | I | clk | CRC 排出/插入控制，高电平有效；启动将 CRC 值插入 data_out |
| `ld_crc_n` | 1 | I | clk | 同步 CRC 寄存器加载控制，低电平有效；将 crc_in 加载到内部 CRC 寄存器 |
| `data_in` | DATA_WIDTH | I | clk | 输入数据 |
| `crc_in` | POLY_SIZE | I | clk | 外部 CRC 输入值，在 ld_crc_n 有效时加载到内部 CRC 寄存器 |
| `draining` | 1 | O | clk | CRC 排出状态指示，高电平表示正在将 CRC 值插入 data_out，寄存器输出 |
| `drain_done` | 1 | O | clk | CRC 排出完成指示，高电平脉冲表示 CRC 已全部插入 data_out，寄存器输出 |
| `crc_ok` | 1 | O | clk | CRC 校验结果，高电平表示残余 CRC 值正确（数据有效），寄存器输出 |
| `data_out` | DATA_WIDTH | O | clk | 输出数据；正常传输阶段直通 data_in，drain 阶段输出 CRC 值，寄存器输出 |
| `crc_out` | POLY_SIZE | O | clk | 内部 CRC 寄存器实时监测输出，寄存器输出 |

### 5.2 信号使用注意

1. `crc_out` 持续输出内部 CRC 寄存器状态，可用于上下文保存；即使在 stall（enable = 0）状态下，crc_out 仍保持当前 CRC 值不变。
2. `crc_ok` 在校验模式下每周期持续更新；当最后一个 CRC 字被处理后，拉低 `enable` 即可冻结 CRC 状态及 `crc_ok` 值，该值即为最终校验结果。`crc_ok` 在生成模式下固定为 0。
3. `drain` 信号仅用于 CRC 生成模式，在校验模式下应保持为 0。
4. `drain_done` 为单周期脉冲信号，指示 CRC 插入完成。

## 6. 时序图

### 6.1 CRC 生成操作（发送/存储模式）

```
          T0    T1    T2    T3    T4    T5    T6    T7    T8
          __    __    __    __    __    __    __    __    __
clk     _/  \__/  \__/  \__/  \__/  \__/  \__/  \__/  \__/
         _________
rst_n            \_________________________________________
                  ___
init_n  _________/   \_____________________________________
                        ____________________
enable  ________________/                    \______________
                                             ___
drain   ___________________________________/   \___________
         ________
data_in ________X___D0___X___D1___X___D2___X___X___X___X___
                              ________________

                              ________________

                                          ___________

         ________ ________ ________

```

**时序说明：** T0 为 init_n 同步初始化；T1~T2 输入数据 D0、D1 进行 CRC 计算，data_out 直通 data_in；T3 拉高 drain 进入排出阶段，draining 拉高；T4~T5 data_out 依次输出 CRC 值 C0、C1；T6 drain_done 单周期脉冲，draining 拉低，排出完成；T7 enable 拉低进入 stall。

```
          T0    T1    T2    T3    T4    T5    T6    T7
          __    __    __    __    __    __    __    __

                        ________________

         ________

         ________ ________

                              ________________
crc_ok  _____________________X__VALID__X_______________
```

**时序说明：** T0 init_n 同步初始化；T1~T2 输入数据 D0、D1；T3~T4 输入 CRC 校验位 C0、C1 参与最终计算；T5 crc_ok 更新输出校验结果。

### 6.3 上下文切换

```
          T0    T1    T2    T3    T4    T5
          __    __    __    __    __    __
clk     _/  \__/  \__/  \__/  \__/  \__/
                              ___
ld_crc_n ____________________/   \_________
         ________ ________ ________
crc_in  ________X__S0'__X__S1'__X__S2'__X___
         ________ ________ ________
crc_out ________X__C0'__X__S0'__X__S1'__X___
```

**时序说明：** T0~T1 正常 CRC 计算，crc_out 反映当前 CRC 状态 C0'；T2 ld_crc_n 拉低，将 crc_in 值 S0' 加载到 CRC 寄存器；T3 crc_out 更新为加载后的值 S0'，之后继续正常运算。
