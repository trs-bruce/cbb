## 1. 功能及应用场景

CBB_GRAY2BIN 是一个参数化位宽的格雷码（Gray Code）转二进制码解码器。将 N 位格雷码编码还原为 N 位标准二进制编码。适用于以下场景：

- **跨时钟域指针解码（CDC FIFO）**：FIFO 读写指针以格雷码形式跨时钟域同步后，需通过本模块还原为二进制码，用于 FIFO 状态判断（满/空）和地址索引。
- **FIFO 指针转换**：异步 FIFO 中，写侧将二进制指针编码为格雷码后同步到读侧，读侧需将同步后的格雷码解码还原为二进制以计算可用空间。
- **编码还原**：接收格雷码编码的总线/状态信号后，还原为标准二进制供后续逻辑使用。

纯组合逻辑，无时钟。综合数据详见 §7。

## 3. 方案分析

### 3.1 原理分析

格雷码转二进制码的数学定义如下：

设 N 位格雷码为 G = (G[N-1], G[N-2], ..., G[0])，对应的 N 位二进制码为 B = (B[N-1], B[N-2], ..., B[0])。

转换公式：

```
B[N-1] = G[N-1]
B[i]   = G[i] ⊕ B[i+1]    (i = 0, 1, ..., N-2)
```

其中 ⊕ 为按位异或。与 bin2gray 不同，gray2bin 的每一位依赖于高位二进制结果，是串行依赖链，无法直接用 `gray ^ (gray >> k)` 形式的单行向量表达式完成。

**实现方法对比：**

| 方法 | 实现方式 | 优点 | 缺点 |
|------|----------|------|------|
| 逐位 assign | 每位生成单独的 assign 语句链 | 意图明确，便于审查 | N 大时代码冗长 |
| for-generate 展开 | generate for 循环 + assign | 代码简洁，可维护，综合可控 | 需注意 generate 命名 |
| always @* + for 循环 | always 块内 integer for 循环（MSB→LSB 阻塞赋值） | 写法直观，串行依赖表达自然 | 需注意阻塞赋值顺序 |

**本设计选择**：always @* + for 循环方法。`always @*` 块（`GRAY2BIN_PROC`）内 MSB→LSB 逐位阻塞赋值，`bin_o[i] = gray_i[i] ^ bin_o[i+1]` 的串行依赖由循环顺序自然表达，综合工具直接映射为 XOR2 门级联链。

### 3.2 设计方案

1. **MSB 直通**：`bin_o[DATA_WIDTH-1] = gray_i[DATA_WIDTH-1]`。
2. **逐位解码**：从高到低，`bin_o[i] = gray_i[i] ^ bin_o[i+1]`（i = DATA_WIDTH-2 down to 0）。`always @*` 块内 for 循环展开，MSB→LSB 阻塞赋值顺序保证依赖正确。
3. **参数约束**：`DATA_WIDTH >= 1`。

**示例（DATA_WIDTH=4）：**

|:---:|:---:|------|
