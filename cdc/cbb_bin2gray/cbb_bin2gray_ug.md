## 1. 功能及应用场景

CBB_BIN2GRAY 是一个参数化位宽的二进制码转格雷码（Gray Code）编码器。将 N 位标准二进制编码转换为 N 位格雷码编码。格雷码的核心特性是相邻数值之间仅有一位发生变化，使其在以下场景中具有独特优势：

- **跨时钟域指针传输（CDC FIFO）**：FIFO 读写指针使用格雷码编码后，跨时钟域同步时最多只有 1 bit 发生亚稳态，配合多级同步器即可安全传递，避免多 bit 同时翻转导致的采样错误。
- **编码转换**：为后续电路（如格雷码计数器、状态机编码）提供编码转换基础功能。
- **降低开关功耗**：对于顺序递增/递减的总线（如地址总线、计数器输出），转换为格雷码后可显著降低 bit 翻转率，减少动态功耗。

纯组合逻辑，无时钟。综合数据详见 §7。

## 3. 方案分析

### 3.1 原理分析

二进制码转格雷码的数学定义如下：

设 N 位二进制码为 `B = (B[N-1], B[N-2], ..., B[0])`，对应的 N 位格雷码为 `G = (G[N-1], G[N-2], ..., G[0])`。

转换公式：

```
G[N-1] = B[N-1]
G[i]   = B[i] ⊕ B[i+1]    (i = 0, 1, ..., N-2)
```

等效的向量表达式：

```
G = B ⊕ (B >> 1)
```

其中 `>>` 为逻辑右移一位（高位补 0），`⊕` 为按位异或。

**实现方法对比：**

| 方法                           | 实现方式                   | 优点                     | 缺点                       |
| ------------------------------ | -------------------------- | ------------------------ | -------------------------- |
| 逐位 assign                    | 每位生成单独的 assign 语句 | 意图明确，便于审查       | N 大时代码冗长             |
| for-generate 展开              | generate for 循环          | 代码简洁，可维护         | 综合结果与逐位 assign 一致 |
| 向量表达式`bin ^ (bin >> 1)` | 单行 assign                | 最简洁，综合工具直接推断 | 需确认综合工具支持此表达式 |

**本设计选择**：向量表达式方法。一行 `assign gray_o = bin_i ^ (bin_i >> 1)` 完成所有位宽的计算，综合工具（Design Compiler / Genus / Vivado 等）均能正确推断为 N-1 个 XOR2 门。

### 3.2 设计方案

1. **输入采样**：`bin_i` 直接接入组合逻辑，无寄存器缓冲。
2. **位移操作**：`bin_i >> 1` 逻辑右移一位，最高位补 0，结果为 `{1'b0, bin_i[DATA_WIDTH-1:1]}`。
3. **异或运算**：`bin_i ^ (bin_i >> 1)` 按位异或，产生格雷码输出。
4. **参数约束**：`DATA_WIDTH >= 1`，不满足时综合结果未定义。

**示例（DATA_WIDTH=4）：**

| 二进制 bin_i | bin_i>>1 | 格雷码 gray_o |
| :----------: | :------: | :-----------: |
|   4'b0000   | 4'b0000 |    4'b0000    |
|   4'b0001   | 4'b0000 |    4'b0001    |
|   4'b0010   | 4'b0001 |    4'b0011    |
|   4'b0011   | 4'b0001 |    4'b0010    |
|   4'b0100   | 4'b0010 |    4'b0110    |
|   4'b0101   | 4'b0010 |    4'b0111    |
|   4'b0110   | 4'b0011 |    4'b0101    |
|   4'b0111   | 4'b0011 |    4'b0100    |
|   4'b1000   | 4'b0100 |    4'b1100    |
|   4'b1001   | 4'b0100 |    4'b1101    |
|   4'b1010   | 4'b0101 |    4'b1111    |
|   4'b1011   | 4'b0101 |    4'b1110    |
|   4'b1100   | 4'b0110 |    4'b1010    |
|   4'b1101   | 4'b0110 |    4'b1011    |
|   4'b1110   | 4'b0111 |    4'b1001    |
|   4'b1111   | 4'b0111 |    4'b1000    |

可验证相邻二进制值对应的格雷码仅一位变化。
